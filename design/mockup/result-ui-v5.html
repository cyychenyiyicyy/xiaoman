设置行的组件规格（对齐 design-system 的 component spec 模式）：行高 56dp（≥48dp 触控）· 左右内边距 14 · 图标槽 24（图标 18）· 标题 15/400 · 副标题 11.5/ink3 · 尾控件右对齐 · 分隔线 1px 且 左缩 14、右缩 0（Material 的 inset divider）。
四种尾控件各管一类：布尔 → switch（不再写"已开启"文字）；数值 → stepper；区间 → slider + 数值；枚举/跳转 → 值 + chevron。危险操作单独一组，标题用赤陶。
模型为什么放进输入框：它是"这次用什么"的临时选择，不是"设置"。所以常驻胶囊 + 弹层；设置页只留一个只读入口（"在输入框里点胶囊也能改"）。
