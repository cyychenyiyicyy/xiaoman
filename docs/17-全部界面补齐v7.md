## 2. 每页的决定（为什么长这样）

### 2.1 采集校对（A1）

| 决定 | 理由 |
|---|---|
| **左原图 / 右结果** | 核对是"看图比对文字"，左右并置才符合动作 |
| 置信度写成 `96%` / `62%` + 低置信行**整行浅底 + 「待确认」** | 状态表达用位置和底色，不用文字解释 |
| 底部 `存为待补` + `入库 3` | 主次分明；数量写在按钮里，省一行状态栏 |
| 工具栏只留 `旋转 / 裁边 / 重拍` | 三项，够用；不堆滤镜 |

### 2.2 复习会话（A2）

| 决定 | 理由 |
|---|---|
| **一屏一卡**，不滚动 | 复习是连续动作，滚动会打断节奏 |
| 评分按钮 **52dp 高、四档、每档带间隔**（1 分 / 1 天 / 4 天 / 9 天） | 把 FSRS 的抽象变成可感知的具体数字 |
| **只有「记得」是 clay 实心** | 一屏一个 filled；它是最常用的档 |
| 右栏作答区 `dashed` + 「写在这里」 | 虚线=可写区域，不用文字说明 |
| 顶部 `3 / 15` | 进度即值 |

### 2.3 题目详情（A3）

| 决定 | 理由 |
|---|---|
| 顶部 **`‹ 2 / 24 ›` 翻页** | 在筛选序列里连续翻，不必退回列表（`docs/10 §1`） |
| **笔记 / 解析 / 作答 三 Tab** | 你的东西和 AI 的东西分家 |
| 底部三动作 `问她 / 相似题 / 写笔记` | 回答"看完这题我现在能干什么" |
| `问她` 带对话图标 | 它是**回到主对话**，不是开新页面 |

### 2.4 知识点详情（A4）

| 决定 | 理由 |
|---|---|
| 掌握度 **34px 大数字** + 条 | 数字给精度，条给位置 |
| 先修行**必须显示对方掌握度**（0.31） | 不显示就看不出"根因在哪" |
| 顶栏 `加入复习` 是唯一主操作 | 其余是浏览 |

### 2.5 确认写入（A5）

| 决定 | 理由 |
|---|---|
| **列 diff 三行**：新卡 2 / 挂到知识点 / 明天起出现 | 不写"这会产生 2 张卡片并关联到…"，用表 |
| 拒绝在左、接受在右 | 平台惯例（破坏性在左） |
| 弹层，不跳页 | 决策要快，不能打断阅读 |

### 2.6 附件选择（A6）

四个 88dp 大按钮，**图标 + 一个名词**（拍照 / 相册 / 文件 / 语音）。没有副标题——"拍照"不需要解释。

### 2.7 错题本（B1 / B2）

| 决定 | 理由 |
|---|---|
| 三栏：筛选 212 / 网格 / 详情 472 | 平板宽度用满，切换零跳转 |
| 卡片里是**题干原文** | 错题是"认出来"的动作（`docs/10`） |
| 知识分类卡：**右侧 24px 大数字**（掌握度） | 纵向扫一遍就能比出谁最烂 |
| `+2` 用 chip 而不是彩色角标 | 单色系，不引入第二种强调色 |

### 2.8 找旧题（B3）

搜索框 + 四路召回 chip（以图 / 语义 / 知识点 / 错因）+ 结果即卡片。**没有说明文案**——输入框空着就该是空的。

### 2.9 知识地图（B4）

大画布 + 浮动信息卡 + 右下角图例。**节点只有三种状态**（薄弱 / 已掌握 / 未学），靠底色和描边区分，不靠颜色编码。

### 2.10 周报（B5）

四数字 → 掌握度变化 → 每天 → 错因 → **一条结论**（"先补「受力分析」"）。
最后那块是 `filled`——**一屏唯一的一个**，因为它是这页要你做的动作。

### 2.11 记忆面板（B6）

每条 = 一句事实 + 日期 + 删除。**没有"为什么记"的解释**——记忆本身就是全部内容。

### 2.12 引导（C1）

只问三项：在学什么（chip 多选）/ 什么时候考 / 每天几分钟。
**没有欢迎页、没有权限请求、没有功能介绍**。第一屏就是提问。

### 2.13 上传队列（C2）

四行四状态：完成（sage 勾）/ 进行中（`活动` 图标 + 百分比）/ 失败（clay 叉 + 重试 chip）。
失败行的重试是 **chip** 不是按钮——因为它嵌在行内。

### 2.14 数据与导出（C3）

三组：导出（apkg / JSON，**带条数**）/ 备份（开关 + 最近时间 + 恢复）/ 存储（题数 / 图片体积）。
「从备份恢复」是本页危险动作，但**没有单独成危险组**——因为它有二次确认页，不在这里发生。

### 2.15 关于与诊断（C4）

版本三项（小满 / Pi / 模型目录）+ 自检四项（服务器 / 数据库 / 模型 / 推送，每项带数字或状态）+ 日志。
**自检项的图标态就是结果**：sage 勾 = 通，clay 叉 = 断。不再写"正常/异常"。

### 2.16 学科选择（C5）

四列网格，「全部」横跨两格并实心，当前科 clay 底，空科写 `空`。

### 2.17 自定义端点（C6）

严格对应 `models.json` 四字段：**名称 / Base URL / API / API Key**，再加模型列表。
API 用 chip 三选（`openai-completions` / `openai-responses` / `anthropic-messages`）——这是 Pi 支持的三种协议，不多不少。

## 3. 全稿共用的规则（已落到 theme.css）

| 规则 | 实现 |
|---|---|
| 字号 6 级 | `--s1…--s6`，**全稿 0 个任意 px**（脚本验证） |
| 间距 7 档 | `--q1…--q6` |
| 图标 | 只 14 / 18 / 22 三档，描边统一 `--stroke:1.7px` |
| 面 | `.c-out`（outlined）/ `.c-fill`（filled）/ flush（无类） |
| 一屏一个 filled | 复习=「记得」；周报=结论卡；确认=「接受」；其余屏为 0 |
| 行高 | 设置行 56dp，弹层内行 48dp |
| 分隔线 | 内缩 14（`.srow + .srow::before`） |
| 数字 | 全部 `.num`（tabular-nums） |
| 无解释文本 | 全稿只有"名词 + 状态值" |
| 无 emoji / 无裸 hex | 全部走 token 与 Lucide |
