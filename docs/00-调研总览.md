## 核心结论

### 1. 你的需求本质不是「做一个 App」，是补一条断掉的链

```
纸质/散落 ──✗──> 结构化 ──✗──> 知识关联 ──✗──> 主动复习
```
三个断点：**痕迹不落库、落库不关联、关联不复发**。产品的全部价值在最后一环会回头改第一环的优先级。

### 2. 最锋利的差异化：**对话即采集**

每一次「去问 AI」都是最真实的薄弱点信号——你只有在不会的时候才问。现有产品（Anki 要你会造卡、NotebookLM 不产复习卡、作业帮给完答案就结束）全都把这颗信号丢掉。
**「AI 只给答案」的解法不是换更强的模型，是让答案流进数据库。**

### 3. 产品形态：**只有一个对话，没有会话列表**

和 ChatGPT 那种「左侧一堆会话」相反：**手机端就是一个对话框，像微信好友，可以一直聊下去。** 这不是偏好，是品类共同形态——Meta Muse 的主界面被明确设计成"一段持续的长对话，就像你和另一个人交谈那样"；开源项目 ownAI 的核心需求第一条就是"No sessions or chats — one flowing conversation"；MIRA"one assistant in one thread"；Inflection Pi 跨会话记忆但主动跳过临时内容。

代价是**上下文会无限膨胀**，所以必须配**三层记忆**（工作记忆交给 Pi 的 compaction / 事件摘要进你的库 / 结构化事实靠工具现查）——**历史不是被"记住"，是被"索引"**。

推论：**功能不是 Tab，是消息的展开**。所有功能都以卡片出现在流里，点开才是全屏页；底部因此**没有 Tab 栏**。

### 4. 市场空白被三家的接缝夹出来了

- 拍摄端**过剩**（作业帮 19 亿题库）
- 结构化**碎片化**（Gemini Notebook 只给摘要）
- 主动复习**全线最弱**（Anki 要你打开才见卡；Quizlet 间隔重复 2026-08 才上线且仅网页版）
- 自建玩家**全是通用助手**，没有一个是学习垂直产品

### 5. 技术骨架（推荐组合）

| 层 | 选择 |
|---|---|
| Android | Kotlin + Jetpack Compose + **Material3**（BOM 2026.09+）+ Room + Ktor + WorkManager |
| 后端 | **FastAPI** + PostgreSQL 18 + **pgvector** + APScheduler |
| 复习调度 | **FSRS-6 用 `py-fsrs`**，绝不自己写算法 |
| 知识图谱 | **PG 边表 + 递归 CTE，不用 Neo4j** |
| AI | **Pi 就是 AI 层本体**（对话循环 / provider / 自带模型目录 / 会话 / compaction / 成本核算全交给它）；你只写 **界面 + ~20 个学习工具 + 一个 ~200 行薄网关**。复习/图谱/统计仍是确定性后端逻辑 |
| OCR | **先用云 API**（¥0.01–0.05/页），50 页/天不要买 GPU |
| 推送 | 自建 **ntfy**（应用外）+ WebSocket（应用内），FCM 国内不可用 |
| 分发 | **GitHub Releases 主 + F-Droid 副**，仓库设 public（一步解决 Actions 额度与 F-Droid 收录） |
| 部署 | Docker Compose + Caddy（自动 HTTPS）+ Tailscale（公网端口可全关） |

### 6. 成本与工时

**≈ ¥35–95/月**（服务器 ¥5.7 + 域名 ¥7 + 模型 ¥7 + OCR ¥15–75）；**M0–M2 约 6 周，到 M5 约 2.5 个月**（业余每周 8–10 小时，合计 **80–120 小时**）。

## 踩到的坑（供复跑参考）

- **GitHub API 直连被 rate-limit**：`Invoke-RestMethod` 连续 12 个仓库全 403，同一时刻 `web_fetch` 取 `api.github.com` 正常。→ 批量取 star 用 `web_fetch`，或加 token。
- **搜索引擎噪声**：`multi_search` 对「personal agent」返回词典释义；query 出现「November」会被劫持到百度百科。→ 用具体英文 query 或直接抓权威页。
- **`web_fetch` 上游 404 / `research` fetch 同样 404**：全程改用 `advanced_search`（keenable 为主）拿事实。
- **子代理产出落到了独立任务文件夹**：`2026-11-15-个人自建App技术栈调研` 是子任务自建的目录，已把产出并入本任务，原目录标「归档」保留。
