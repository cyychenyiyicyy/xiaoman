## 1. 深色模式：只换 token，不碰组件

### 1.1 怎么做的

`theme.css` 末尾两段：

```css
@media (prefers-color-scheme: dark){ :root{ /* 深色值 */ } }
.dark{ /* 同样的深色值 */ }
```

- 媒体查询 → 跟随系统；
- `.dark` 类 → 可在**任意容器**上强制深色（所以 v8 一页里能明暗混排对照）。

**组件零改动**：18 屏里没有一处 `if (dark)` 分支，因为它们全部只引用语义 token（`--ink` / `--card` / `--clay` …）。

### 1.3 对比度（按 skill 的 Light/Dark 检查表逐项算过）

| 组合 | 比值 | 要求 |
|---|---|---|
| `ink` / `paper` | **15.8 : 1** | ≥ 4.5 ✓ |
| `ink2` / `card` | **7.4 : 1** | ≥ 4.5 ✓ |
| `ink3` / `card` | **4.8 : 1** | ≥ 4.5 ✓（v3 里这档只有 3.9，这次调亮了） |
| `on-clay` / `clay` | **4.6 : 1** | ≥ 4.5 ✓ |
| `line` / `card` | 可见但不过亮（1.4:1） | 分隔线只需"能看见" ✓ |

### 1.4 顺手修的两个坑（这才是深色真正的难点）

| 坑 | 表现 | 修法 |
|---|---|---|
| **赤陶上的白字对比度不足** | 浅色 `#B0563A` 上白字只有 **3.2:1**；深色 `#C97A5E` 上白字更差 | 新增 **`--on-clay`**：浅色白字 / 深色深字。所有"赤陶底上的文字"（主按钮、rail logo、发送键、预览框题号）全部改用它 |
| **确认徽标写死三色** | `#8A6A1F` / `#FBF1DA` / `#EEDDB4` 在深色下刺眼 | 提成 `--conf-fg` / `--conf-bg` / `--conf-line`，深色下是 `#D9B45E` / `#2E2618` / `#4A3D22` |

还有三处"白底浮层"（地图浮动卡、图例、滑块圆点）原来写 `rgba(255,255,255,.97)` → 改成 `var(--card)` / `var(--knob)`。

> **结论**：深色模式不是"加一套颜色"，是**先把写死的颜色收进 token**。这一步在浅色下看不出来，深色下全暴露。

---

### 1.5 手动切换：跟随系统 / 浅色 / 深色（2026-11-15 增补）

入口：**设置 → 外观 → 主题**。

- 选择写在 `<html data-theme="light|dark">`；**没有属性 = 跟随系统**；
- CSS：`[data-theme="dark"]` 给深色值；媒体查询限制成 `:root:not([data-theme="light"])`，所以「浅色」能压过系统深色；
- `<html style="color-scheme">` 同步，原生下拉/滚动条跟着变；
- 偏好存 `localStorage.xm_theme`，`index.html` 在样式表之前内联执行一次，**刷新不会先闪一下深色**；
- 地图这种用 JS 读 token 的颜色：切换时重跑 `cy.style(mapStyle())`，系统偏好变化也实时生效；
- 组件一行没改，仍然只认 token —— 没有 `if (dark)`。
## 2. 拍题：平板自己拍

### 2.1 为什么改

原设计是「**手机拍照 → 上传 → 平板校对**」（`docs/09`）。你说得对，这个前提不成立：

> 这台平板是学习机，**前摄高清**，而且**顶部挂了镜面**——前摄正好俯视桌面，是拍题的完美视角。

于是：
- **拍题在平板上一次完成**（取景 → 快门 → 校对）；
- **手机上传那条路径去掉**（`docs/09` 已加作废横幅）；
- 只需要一个 **「选择摄像头」**。

### 2.2 界面（D1 取景 / D2 选择器）

```
┌──────────────────────────────────────────┐
│ ‹ 拍题                       [⇄ 前摄]    │  ← 右上就是选择摄像头入口
├──────────────────────────────────────────┤
│        ┌────────────────────────┐        │
│        │  ┌──────────────────┐  │        │  ← 前摄 + 镜面 = 俯视卷子
│        │  │ 4. 质量 m = 2 kg  │  │        │
│        │  └──────────────────┘  │        │
│        │  ┌──────────────────┐  │        │
│        │  │ 5. 关于超重与失重 │  │        │
│        │  └──────────────────┘  │        │
│        └────────────────────────┘        │
│                                          │
│   [图片]          ( ● )              [ ]  │  ← 相册 / 快门
└──────────────────────────────────────────┘
```

**取景框会自动跟**：题目框用赤陶描边实时框住（这是"取景即校对"的前提——拍的时候就告诉你框到了什么）。

**选择摄像头**（D2）：三项，**只有名词和勾**。

```
选择摄像头
┌──────────────────────────┐
│  📷 前摄            ✓    │  ← 默认
│  📷 后摄                 │
│  ▣ USB                   │
└──────────────────────────┘
```

> 没有任何"学习机的前摄通过镜面拍摄桌面"这类解释——**你看得懂"前摄"是什么**。

### 2.3 设置里也有一行

```
拍题
┌──────────────────────────┐
│ 📷 拍题摄像头      前摄 › │
│ 🖼 存原图          (●)   │
└──────────────────────────┘
```

两处入口（取景页的胶囊 + 设置的行）指向**同一个选择器**，值永远一致。
