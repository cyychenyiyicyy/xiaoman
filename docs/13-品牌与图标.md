## 1. 名字：**小满**

| 项 | 值 |
|---|---|
| 中文名 | **小满** |
| 英文短名 | `Xiaoman` |
| Android 包名 | **`site.e1e.xiaoman`** |
| 访问 | 直接用 IP（2026-11-14 拍板：不做域名） |

### 为什么是它

**① 名字本身就是产品说明。** 小满是二十四节气第八个——麦子开始灌浆，**将满而未满**。这个状态精确对应"学习"：不是"学完了"，是"正在变满"。

**② 有分寸感。** 二十四节气里，小满之后是芒种，**没有"大满"**。古人刻意留了这个缺：满招损。而学习最要紧的就是"永远差一点"——那一点才让人继续。

**③ App 名 = 她的名。** 她叫小满，App 也叫小满。这意味着你不用记两个词，而且"打开 App"和"找她"是同一件事——这正是 [07](07-产品设计-单一会话.md) 里"单一关系"的产品形态在命名上的落地。

**④ 读起来是个女孩名。** 不叫"学习助手""智慧课堂"，因为那会立刻把它变回工具。

### 落选的三个（都认真想过）

| 名字 | 出处 | 为什么不选 |
|---|---|---|
| **问渠** | 问渠那得清如许，为有源头活水来 | 书卷气最好，但两个字念着生硬，且"渠"字不适合做吉祥物/人称 |
| **温故** | 温故而知新 | 直接对应复习，但**把产品做窄了**——我们不只是复习，还有采集、提问、图谱 |
| **拾遗** | 拾遗补阙 | 好听，但"拾"是被动补漏，不是"陪你长" |

## 2. 图标：**未满的环 + 一颗刚落进去的种子**

### 构图

```
一个几乎闭合的环（缺口在右上，30° 半宽）
缺口内、靠近环内侧，一枚实心圆
```

三层读法，一层比一层深：

| 层 | 含义 |
|---|---|
| **形** | 环没闭合 → **未满** |
| **事** | 种子已在缺口内 → **已经进来了（入库/记住）** |
| **势** | 只差一步就闭合 → **将满** |

它同时是这个 App 的三个动作：**收进来、连起来、还差一点**。

### 几何（精确值，SVG/PNG 共用）

| 参数 | 512 基准 | 108dp 自适应（×0.88 缩进安全圆） |
|---|---|---|
| 环中心半径 `r` | 148 | 27.48 |
| 描边宽 `w` | 36 | 6.68 |
| 缺口中心角 | −70°（右上） | 同 |
| 缺口半宽 | 30° | 同 |
| 种子半径 | 26 | 4.83 |
| 种子中心半径 | 88 | 16.34 |

- 弧从 **−40° 顺时针到 290°**（330° 弧长），两端是径向平切；
- 种子中心 = `(286.1, 173.31)`（512 基准）；
- 自适应前景最大外径 **30.8 / 33**（66dp 安全圆内），**任何遮罩都不会切到**。

### 为什么种子要"往回收"

第一版把种子放在环的中线上（缺口正中央），结果 32px 下**像 loading 转圈**。往圆心收 60 单位后，它变成"掉进碗里的东西"，语义清楚了，小尺寸也不粘连。

### 淘汰过程（诚实记录）

| 方案 | 问题 |
|---|---|
| 缺口朝上 + 种子在正上方 | **像笑脸**（两个弧端像耳朵，种子像鼻子） |
| 缺口朝上 + 种子在正上外侧 | 点被推到环外，32px 下和环分离，像感叹号 |
| 缺口右上 + 点**落在环上** | **像 loading 转圈**（本轮的起点） |
| 缺口右上 + 环内**无点** | 干净但太像字母 **C**，没有"种子"这层意思 |
| **麦穗**（茎 + 三对斜撇） | 32px 下糊成**鱼骨** |
| **麦粒**（旋转椭圆 + 中脉） | 好看，但读起来像**咖啡豆**，和"学习"无关 |
| **半满**（环 + 左半实心） | 像**深色模式开关** |

**结论：缺口右上 + 种子落在环内。** 它不是最"好看"的那个，但它是**最扛缩小、也最有话可说**的那个。

### 平涂 vs 对角渐变

两个都出了。你用 ClassTool 时选的是**对角渐变满版**（`C66C4E → 96442C`），所以渐变版大概率也是你的菜。默认给平涂（更稳、更省事、任何底色都不脏），要换一行改。

## 3. Android 资产映射

| 文件 | 放到哪 | 说明 |
|---|---|---|
| `ic_launcher_foreground.svg` / `-432.png` | `res/drawable*/ic_launcher_foreground.xml` | 前景层，透明底 |
| `ic_launcher_background-432.png` | `res/mipmap-*/ic_launcher_background.png` | 背景层（纯色可改用 `<color>` 资源） |
| `ic_launcher_monochrome.svg` / `-432.png` | `res/drawable/ic_launcher_monochrome.xml` | **Android 16 强制主题化图标用，必须提供** |
| `icon-{48,72,96,144,192}.png` | `res/mipmap-{mdpi,hdpi,xhdpi,xxhdpi,xxxhdpi}/ic_launcher.png` | 旧系统（API < 26）兜底 |
| `icon-512.png` | 商店/关于页 | 512×512 |
| `icon-inverse-512.png` | 关于页、浅色底 | 米底陶标 |

`res/mipmap-anydpi-v26/ic_launcher.xml`：

```xml
<adaptive-icon>
  <background android:drawable="@color/clay"/>          <!-- #B0563A -->
  <foreground android:drawable="@drawable/ic_launcher_foreground"/>
  <monochrome android:drawable="@drawable/ic_launcher_monochrome"/>
</adaptive-icon>
```

> ⚠️ **`monochrome` 必须有**。你的讯飞平板若是 Android 16+，系统会强制主题化图标且 **App 不能 opt out**；不提供这一层就会被系统自己染色（通常是灰色糊团）。

## 7. 图标第二轮：几何被否，改走字标（2026-11-14 追加）

用户对「未满的环 + 种子」及其全部变体给出**"还是不好看"**。记录这轮的判断与资产：

### 7.1 为什么几何标志这条路走不通

| 尝试 | 结果 |
|---|---|
| 缺口右上 + 环内种子（含 4 个角度变体） | 像 loading 转圈 / 像笑脸 / 像字母 C |
| 麦穗（程序绘制，茎 + 三对斜撇） | 32px 糊成鱼骨；放大后像**叶脉** |
| 麦粒三连大特写（出血） | 像**花瓣/叶片**，读不出"麦" |
| 陶碗 + 麦粒 | 未做——先被否了方向 |
| 半满（环 + 左半实心） | 像深色模式开关 |

**结论：居中的抽象标志对这位用户无效。** 他在 ClassTool 上最终选的是「具体物体 + 满版渐变 + 出血」，说明他要的是**有物象的东西**。

### 7.2 图像模型暂时不可用

`minimax_generate_image` 报 **2056 用量上限**：通用额度 5 小时窗口剩 0%、本周剩 4%（窗口 2026-11-14 20:00 重置）。所以**插画版这轮做不出来**，只能程序绘制 → 效果如上表，不达标。

### 7.3 改走汉字字标（当前最佳）

四选一（`brand/logo-pick.png`）：

| # | 内容 | 判断 |

| 2 | 「满」黑体 1.30 | ❌ 同上，且黑体更硬 |
