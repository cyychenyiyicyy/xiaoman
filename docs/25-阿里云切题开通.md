# 25 · 阿里云切题：怎么开通、怎么调用

> 2026-11-15。目标：拿到**能用的凭据**，让 `server/app/services/papercut.py` 直接跑起来。

## 0. 先纠正一件事

「免费」指的是**配额免费**，不是「不用凭据」。阿里云所有 API 都要身份，切题有三种身份：

| 方式 | 需要什么 | 费用 | 能不能不传公网图 |
|---|---|---|---|
| **读光体验馆网页** | 无 | 全免费 | 只能手动试，**不能自动化** |
| **云市场 APPCODE** | APPCODE + 调用地址 | 0.01 元/500 次试用，之后 167 元/1000 次 | ✅ 支持 base64 |
| **官方 CutQuestions** | AK/SK + 百炼业务空间 id | **每天免费 1000 次** | ❌ `image` 必须是公网 URL（要 OSS） |

> 你贴的那个 `sk-ws-...` 我实测过：它是**百炼工作空间 API Key**（DashScope 用），可以调百炼模型，但**调不了切题**——`POST /api/v1/services/edututor/cut-questions` 返回 `Model not exist`；官方切题端点是 ROA 签名接口，只认 AK/SK。
> 这个 key 现在等于已经在聊天里暴露，**建议去百炼控制台作废重建**。

## 方案 A（最省事，推荐先跑）：云市场 APPCODE

1. 打开你发的商品页 → 选 **「0.01元/500次」** → 购买（已买过就跳过）
2. 阿里云控制台 → **云市场 → 已购买的服务** → 找到「扫描版试卷切题OCR」→ 点 **「应用信息」**
3. 复制两样东西：
   - **AppCode**（一串 32 位十六进制）
   - **调用地址**（形如 `https://xxxxx.market.alicloudapi.com`，每个商品不同，别用别家的）
4. 填进 `server/.env`：

```env
PAPERCUT_AUTH=appcode
PAPERCUT_APPCODE=<AppCode>
PAPERCUT_ENDPOINT=https://xxxxx.market.alicloudapi.com/educationservice/papercut
```

5. 重启 API，拍一页即可。**不需要 OSS、不需要公网图**（代码直接发 base64）。

> 如果你买的是**精细版结构化切题**，路径可能不是 `/educationservice/papercut`，把文档里的请求路径一起贴我。

## 方案 B（每天免费 1000 次）：官方 CutQuestions

### B1. 开通与拿 id

1. 阿里云 → **百炼（Model Studio）控制台** → 开通服务（实名认证要过）
2. 左侧 **业务空间**，记下 **WorkspaceId**（形如 `llm-1ijrzuv3v0ivvls7`）

### B2. 拿 AccessKey

1. 阿里云控制台右上角头像 → **AccessKey 管理**
2. 建议「**开始使用子用户 AccessKey**」：建一个 RAM 用户，权限只给 `edututor:CutQuestions`
3. 记下 **AccessKey ID** 与 **AccessKey Secret**（Secret 只显示一次）

### B3. 建 OSS 桶（因为接口要 URL）

1. 控制台 → **对象存储 OSS** → 创建 Bucket（私有即可）
2. 记下 **Bucket 名** 与 **Endpoint**（例如 `https://oss-cn-hangzhou.aliyuncs.com`）
3. 代码会用它签一个 **1 小时有效的临时 URL** 传给切题接口，桶不用公开读

### B4. 填配置并重启

```env
PAPERCUT_AUTH=aksk
ALIYUN_AK_ID=<AccessKey ID>
ALIYUN_AK_SECRET=<AccessKey Secret>
PAPERCUT_WORKSPACE_ID=llm-xxxxxxxx
OSS_BUCKET=<bucket 名>
OSS_ENDPOINT=https://oss-cn-hangzhou.aliyuncs.com
```

代码路径（已实现）：
```
本地图 → oss2.put_object → sign_url(1h) → SDK CutQuestions（AK/SK 签名）
       → data(JSON 字符串) → normalize() → groups（每题一组，bbox 归一化 0–1000，答案保留）
```

## 2. 切题接上之后，流水线怎么变

```
拍 → OSS（仅官方版）/ base64（云市场）
   → 切题 API（题组由算法切）
   → normalize() → groups
   → 复核界面（选题）→ 确认入库 question
```

**LLM 不再参与切题**，只在你问「讲讲这题」时参与讲解——这正好符合「题组别让模型猜」的原则。
