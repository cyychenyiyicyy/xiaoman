# 26 · 从「学科空间」改成「对话列表」（2026-11-15）

用户判断：每个科目一个无限长空间不如 ChatGPT 式的一条条对话，决定改回**对话列表**。

---

## 1. 数据与接口

| 项 | 变化 |
|---|---|
| `conversation` | 新增 `title`（首条用户消息前 30 字自动写入） |
| `GET /conversations?subject=` | 列表：标题 / 学科 / 条数 / 最后一条预览 / 更新时间；**空对话不返回** |
| `POST /conversations {subject}` | 新建 |
| `PATCH /conversations/{id}` | 改名 / 改学科 |
| `DELETE /conversations/{id}` | 删除（连消息一起） |
| `GET /messages?conversation_id=` | 按对话取消息；没有对话时返回空，不再顺手建空对话 |
| `POST /chat` | 新增 `conversation_id`、`subject`；新建对话时用首条消息生成标题 |
| Pi 会话 | 一个对话一个 session 文件（`conv:<id>`），不再按学科共用 |

## 2. 界面

- **首页（L0 对话）**：`新对话` 主按钮、学科筛选 chips、按日期分组（今天/昨天/M/D）、标题 + 学科标签 + 最后一条预览；空态给「新对话」动作。
- **新对话**：弹层选科目（九科）→ 建对话 → 进聊天。
- **聊天页**：左上 `‹` 回列表，标题大字 + 学科小字；输入区发送带 `conversation_id`。
- **移除**：学科左右侧栏（`#spaces`）、「今天」概览首页、强制回今天 / 记住上次学科。
- 题库、记忆、设置保持原样；「引用该题」现在会**复用同科对话或新建一个**再放进输入框。
