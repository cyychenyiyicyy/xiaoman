# 29 · 自动标题 + 一级页导航（2026-11-15）

## 1. rail 高亮与独立页

- 之前的 bug：点「本周」时「对话」仍亮着（`chat.classList.toggle('on', ...)` 漏算了 week）。
- 现在只有当前一级页高亮；**本周 / 题库 / 记忆 / 设置都是独立一级页**，对话侧栏在这些页面自动收起
  （`renderConvSide()` 在 `view !== 'chat'` 时 `hidden`，并补了 `.convside[hidden]{display:none}`，
  否则 `display:flex` 会覆盖 `hidden`）。

## 2. 标题字号

- 聊天页顶栏标题：19px → **15px**（`--s4`），学科仍是 11px 小字；
- 侧栏对话标题 13px、预览 13px→11px，两行结构不变。

## 3. 自动总结标题

`POST /conversations/{id}/autotitle`：
- 取前 8 条消息交给模型，要求「不超过 10 个字、说清在问什么、只输出标题」；
- 每个对话只做一次（`title_auto` 标记）；
- 模型输出为空（思考模型把 token 吃光）时兜底为她第一句话前 16 字；
- 前端在每轮回答结束后异步调用，不改标题就不重绘。

实测/回填示例：

```
我想搞懂二次函数的最大值最小值怎么求 → 二次函数区间最值
滑块在斜面上匀速下滑，动摩擦因数怎么求 → 斜面动摩擦因数
英语作文怎么开头？给我一个句子。 → 英语作文如何开头
```

历史对话已批量补齐标题。
