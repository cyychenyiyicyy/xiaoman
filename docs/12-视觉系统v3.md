**归纳成三条纪律**（就是这版的骨架）：

1. **排版 + 间距 + 克制**，好看不靠装饰。
2. **严格间距尺度**，不许任意值（v2 里的 13px/14px 内边距就是"没尺度"的痕迹）。
3. **用字号/字重的对比做层级，不要用边框和底色堆层级。**

## 2. 字族：**全无衬线**（v3.1 定稿）

**为什么最终全部去掉衬线**——三条理由，第二条是决定性的：

1. **中文衬线只有两档字重**（SimSun 400/700、NotoSerifCJK 400/700）。24–34px 放大后笔画发虚、横竖不均。
2. **数字和公式在衬线里对齐差**。`−1 < x < 4`、`ax² + bx − 2` 这种混排，衬线体的数学符号与中文字重不匹配，一眼能看出"两套字在打架"。你是数学/物理为主的使用场景，这一条最要命。
3. **两个只能用极端方式并存**：要么全衬线（糊），要么混排（打架）。**砍掉一个是最干净的解法。**

**只用一个字族**（符合"≤2–3 个字族"规则的上限，也更省）：

| 用途 | 字族 |
|---|---|
| 全部（标题、正文、数字、按钮、标签） | **Instrument Sans** 400 / 500 / 600 |
| 中文回落 | 思源黑体 / 微软雅黑（桌面）· Noto Sans CJK（Android 内置） |

**没有衬线，层级怎么来？** 三样东西顶替它：

- **字号**：34 / 24 / 19 三档抬头，15 / 13 / 11 三档正文；
- **字重**：只有 400、500、600 三档，**抬头一律 500**（无衬线 500 有骨架但不笨）；
- **字距 + 颜色**：抬头收紧 `-0.015em`～`-0.02em`，标签放开 `+0.08em`；三级墨色拉层次。

> 牺牲的是"书卷气"，换到的是**利落 + 数字清楚 + 一套字永远不打仗**。对每天看 40 分钟数学的人来说，后者更重要。

## 3. 字号：收到 6 级（v2 是 8 级）

| Token | 字号 | 行高 | 字族 | 用在哪 |
|---|---|---|---|---|
| `s1` | **34** | 1.24 | 无衬线 500 | 引导大标题、掌握度大数字 |
| `s2` | **24** | 1.30 | 无衬线 500 | 页面标题、知识点名、题干（复习页） |
| `s3` | **19** | 1.50 | 无衬线 500 | **她开口的第一句**、强调句 |
| `s4` | **15** | 1.72 | 无衬线 400 | 正文（唯一正文尺寸） |
| `s5` | **13** | 1.60 | 无衬线 400 | 次要说明、卡片副文、按钮文字 |
| `s6` | **11** | 1.45 | 无衬线 500 + 字距 .08em | 标签、时段、角标、元信息 |

**关键改变：不再靠"加大字号"区分标题。**
v2 里卡片标题 16 / 正文 14.5 / 说明 13 挤在一起，只能靠**加边框**分层。v3 里：

- 卡片标题 = **正文同尺寸 15 + 字重 500 + 主墨色**
- 卡片副文 = **13 + 次墨色**
- 分组标题 = **11 + 字距 + 三级墨色**

**尺寸只差一档，靠字重和颜色拉开**——这就是研究里说的「typographic contrast instead of decorative chrome」。6 级够用，8 级是浪费。

> 全局检查：v3 的 HTML 里**没有一个非 token 的 font-size**（我用脚本替换干净了，验证过）。

## 4. 间距：严格 7 档

```
4 · 8 · 12 · 20 · 32 · 52      （比率约 1.6，和 1.618 很接近）
```

- **段内** 4 / 8
- **段间** 12 / 20
- **区块间** 32 / 52
- **页面留白**：手机 20，平板详情 32–52

**没有 6、10、14、16、24、28。** v2 里那些"13px 卡片内边距""11px 段落间距"全部被吸收进这 7 档。

效果：**同样内容，v3 看起来更整齐，却更空。** 空出来的地方就是"贵"的感觉来源。

## 5. 三级面（取代"全是白卡片"）

v2 的问题：**所有东西都是白底 + 1px 边框**，于是"什么重要"看不出来。v3 用三种面：

| 面 | 长相 | 用在哪 | 规则 |
|---|---|---|---|
| **flush** | 无边框、无底色，直接排在纸面上 | 她的话、列表行、知识点列表、段落 | **默认就用它**，绝大多数内容 |
| **outlined** | 1px 描边 + 白底 + 圆角 10 | **只有"可点/可操作"的东西** | 点了会有反应才配得上边框 |
| **filled** | 浅纸色底（`#F4F1EA`）+ 圆角 10 | **需要你决策的东西**（确认卡、当前选中） | ⚠️ **一屏最多一个** |

**"一屏最多一个 filled"是这版最狠的一条。** 因为一旦有两个，就都不重要了。

配套：**卡片圆角 12 → 10**（更利落），按钮圆角 10 → 8，描边色从 `#E4E1D6` 减轻到 `#E8E4DA`。

## 6. 颜色：只剩两个色相

| Token | 值 | 用途 |
|---|---|---|
| `paper` | `#FBFAF7` | 页面底（比 v2 更暖一点点） |
| `card` | `#FFFFFF` | outlined / filled 面 |
| `fill` | `#F4F1EA` | 唯一的 filled 面 + 你的消息气泡 |
| `ink` | `#1A1917` | 主文字 |
| `ink2` | `#6E6A62` | 次要文字 |
| `ink3` | `#A09B90` | 三级文字、标签 |
| `line` | `#E8E4DA` | 1px 描边、分隔线 |
| **`clay`** | **`#B0563A`** | **主色**：主按钮、当前导航项、薄弱数字、链接 |
| **`sage`** | **`#5F7355`** | **只一处**：表示"已掌握/已完成"（一周里最多出现几次） |

**赤陶从 `#C96442` 降到 `#B0563A`**：v2 那个偏"橙"，大面积用会土；这个更接近陶土、更闷、更耐看。

**深色模式**（未出稿，规则同构）：paper `#151412`、card `#1D1C19`、fill `#25231F`、ink `#EFEBE3`、clay `#C97A5E`。

## 7. 数字系统：全部 tabular

这是一条**被低估的优化**。你是数字密集场景（掌握度、题数、天数、分钟、日期、分数）。

```css
.num { font-variant-numeric: tabular-nums; font-feature-settings: "tnum"; }
```

- 所有数字**等宽** → 列表里穿成一条竖线（v3 稿里 "0.31 / 0.58 / 0.46" 右对齐就是靠这个）；
- 掌握度**从"5 个方块"改成"一个大数字 + 一个词"**（弱 / 中 / 稳）——方块看着像游戏，数字更像成绩单；
- 知识点列表把掌握度放到**右侧 24px 大数字**，柔和地排成"刻度列"，一眼比出谁最烂。

## 8. 五处结构优化（不只是换皮）

| # | v2 | v3 | 为什么 |
|---|---|---|---|
| **1** | 顶栏：`[头像] 小满 · 今天陪你学物理` | **两级**：上排 11px「小满 · 陪你学 · 第 47 天」，下排 **24px 衬线「物理 ▾」** | 学科变成**页面标题**，切换器从"小字提示"升为"主控"，也更好点。头像下沉成小圆火漆 |
| **2** | 「全部」= 四张科目卡 + 两个按钮 | **四行无框清单**（科名 + 一句说明 + 数字 + ›），按钮只留主次各一 | 四条并排的卡片会互相抢注意力；无框清单能**竖着读**，数字还能对齐 |
| **3** | 四档评分用了 4 种底色（黄/灰/绿/赤陶） | **全白描边 + 一个推荐档用赤陶**，每档下加"下次间隔" | 四种底色像"贴纸"，且绿色会和 sage 打架；把"间隔"写出来让 FSRS 可感知 |
| **4** | 知识点聚合卡：掌握度条 + 彩色 `+N` 绿角标 | **右侧大数字 + 小字新增长条** | 进度条在列表里占宽又不好比；大数字能直接纵向比较 |
| **5** | 消息里的先修链用"5 个方块" | **三行 flush 列表 + 右对齐数字** | 方块在中文界面里显得幼稚；数字对齐后"0.31 最弱"瞬间可见 |

## 9. v2 → v3 对照（一眼看清改了什么）

| 项 | v2 | v3 |
|---|---|---|
| 字族 | Lora + Inter（全衬线标题 + 无衬线正文混着用） | **只用 Instrument Sans 一个字族**（v3.1 去衬线），中文回落系统黑体 |
| 字号 | 8 级（32/24/20/16/14/13/12/11） | **6 级**（34/24/19/15/13/11） |
| 间距 | 4/8/12/16/24/32（还有 13、14 混入） | **4/8/12/20/32/52，7 档，无例外** |
| 层级手段 | 全部白卡 + 描边 | **flush / outlined / filled 三级，一屏一个 filled** |
| 掌握度 | 5 个方块 + 进度条 | **大数字 + 一个词** |
| 数字对齐 | 默认 | **全部 tabular-nums** |
| 主色 | `#C96442`（偏橙） | **`#B0563A`（陶土，更闷）** |
| 圆角 | 12 | **10**（卡片）/ 8（按钮） |
| 顶栏 | 头像 + 名字 + 学科小字 | **小字身份 + 大字学科** |

## 10. Compose 落点（能直接抄）

```kotlin
// 字族
val Sans  = FontFamily(Font(R.font.instrument_sans_regular), Font(R.font.instrument_sans_medium))
val Serif = FontFamily(Font(R.font.source_serif_4_regular))
// 中文永远走系统：FontFamily.SansSerif / .Serif（Noto CJK 内置，零体积）

val AppTypography = Typography(
    displayLarge  = TextStyle(fontFamily = Serif, fontSize = 34.sp, lineHeight = 1.24.em, letterSpacing = (-0.02).em),
    headlineMedium= TextStyle(fontFamily = Serif, fontSize = 24.sp, lineHeight = 1.30.em, letterSpacing = (-0.015).em),
    titleLarge    = TextStyle(fontFamily = Serif, fontSize = 19.sp, lineHeight = 1.50.em),
    bodyLarge     = TextStyle(fontFamily = Sans,  fontSize = 15.sp, lineHeight = 1.72.em),
    bodyMedium    = TextStyle(fontFamily = Sans,  fontSize = 13.sp, lineHeight = 1.60.em),
    labelSmall    = TextStyle(fontFamily = Sans,  fontSize = 11.sp, lineHeight = 1.45.em,
                              fontWeight = FontWeight.Medium, letterSpacing = 0.08.em),
)

// 间距：只有这 7 个
object Sp { val q1 = 4.dp; val q2 = 8.dp; val q3 = 12.dp; val q4 = 20.dp; val q5 = 32.dp; val q6 = 52.dp }

// 三级面：做成三个 Composable，而不是三个 modifier 随手写
@Composable fun Flush(content: @Composable ColumnScope.() -> Unit) { Column(Modifier.fillMaxWidth(), content = content) }
@Composable fun Outlined(content: ...) { Surface(shape = RoundedCornerShape(10.dp), border = BorderStroke(1.dp, Line), color = Card, ...) }
@Composable fun Filled(content: ...)   { Surface(shape = RoundedCornerShape(10.dp), color = Fill, ...) }

// 数字等宽
val TabularNum = TextStyle(fontFeatureSettings = "tnum")
```

**三条纪律写进代码**：
1. `Sp` 只有 7 个常量 → 任何 `.padding(13.dp)` 都是错的；
2. `AppTypography` 只有 6 个级 → 任何 `fontSize = 16.sp` 都是错的；
3. `Filled` 一个屏最多用一次 → 我在 code review 里会数。

## 12. 一句话

> **v2 是"看起来像 Anthropic"；v3 是"用 Anthropic 的方法做我们自己的东西"。**
> 方法只有三句：**字族混着用但只在三处点睛**、**间距和字号各有固定档、不许多一个**、**层级靠字重和空，不靠边框和颜色**。
