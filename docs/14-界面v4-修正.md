## 1. 图标：来自 Lucide，内联进 HTML

- 来源：`lucide-static`（**MIT**），下载 29 个 → 放进 `mockup/icons/`
- 用法：把每个 `<svg>` 的内层 path 提取成 `<symbol id="i-xxx">`，用 `<use href="#i-xxx">` 引用
- **好处**：0 次外部请求、可 `currentColor` 染色、1 条 path 数据 ≈ 100 字节

九科映射（这是「学科选择」不再丑的关键）：

| 科目 | 图标 | Lucide 名 |
|---|---|---|
| 语文 | 摊开的书（带行） | `book-open-text` |
| 数学 | **Σ** | `sigma` |
| 英语 | 语言（A + 文） | `languages` |
| 物理 | **原子** | `atom` |
| 化学 | 锥形瓶 | `flask-conical` |
| 生物 | 叶 | `leaf` |
| 政治 | 天平 | `scale` |
| 历史 | 柱廊（神庙） | `landmark` |
| 地理 | 地球 | `globe` |
| 全部 | 太阳 | `sun` |

其余：`clock` 时间 · `zap` 本周/思考档位 · `cpu` 模型 · `bell` 通知 · `palette` 外观 · `database` 数据 · `camera` `mic` `plus` `arrow-up` 输入条 · `check` 选中 · `circle-dot` 对话 · `sparkles` 地图 · `more-horizontal` · `chevron-down/right`

## 2. 首页为什么改成双栏

v3 的「全部」是：

```
[轨]        ┌──── 740px 居中单列 ────┐        （右边一大片空白）
            │ 早上好 · 四行清单 · 按钮 │
```

问题不是"内容少"，是**构图失衡**——1280 宽的屏幕上只有左侧一半有东西。

v4：

```
[轨]  ┌── 左 452：她说话 ──┐┌── 右：今日面板 ──────────┐
      │ 早上好。今天四科有事 ││ 今日            共 22 张 │
      │ 一共 22 张要复习    ││ ⚛ 物理  12 张  0.31  › │
      │ 先从物理开始？      ││ Σ 数学   5 张  0.34  › │
      │ [从物理开始][自己安排]││ 语 英语  3 词  0.62  › │
      │ 上次停在这里…       ││ 🧪 化学  2 道  0.55  › │
      │                     ││ ＋ 还有五科空着        │
      │ ┌ 输入条 ┐          ││ ── 本周 ──             │
      └─────────────────────┘│ 84 张 · 3h20 · 0.61 ↑  │
                             │ [查看本周报告]          │
                             └────────────────────────┘
```

**分工**：左栏只放**她的话**（≤3 句 + 一个主按钮），右栏放**数据**（四科 + 本周）。

这条分工同时解决了两件事：
1. 页面不空；
2. **她说话的地方不会被数字打断**——这对"伙伴感"很重要。

手机上（<600dp）右栏降级为**底部弹层**，从顶栏那个「今日」入口拉起，不占正文。

## 3. 学科选择：从文字胶囊 → 图标网格

**旧**：`物理 ▾` 点开是一列纯文字（十个"字"）。
**新**：底部弹层里 **4 列 × 3 行格子**，每格：

```
┌──────────────┐
│ ⚛   物理     │   ← 图标 + 科名
│     12 张    │   ← 待办数（tabular）
└──────────────┘
```

- **「全部」横跨两格**，用实心赤陶底，一眼是"当前所在空间"；
- 当前学科用 `clayBg` + 白底图标，和「全部」区分；
- 空科目显示「空」而不是「0」——**"空"是邀请，"0"是失败**；
- 弹层底部一句「切换只换空间，不新建对话」，把 11 的设计意图写在用户看得见的地方。

顶栏那个胶囊也换了：`⚛ 物理 ⌄`——**图标让"物理"从一个词变成一个可识别的记号**。

## 4. 模型选择（新页）

左列表 + 右规格，横向用满：

| 列 | 内容 |
|---|---|
| 左（520） | 对话模型列表：名称 + provider + **价格 / 上下文** + 选中勾；下面是**思考档位**（关 / 中 / 高）与一句适用建议 |
| 右 | 当前模型的规格表（provider / 上下文 / 最大输出 / 单价 / 峰时倍率 / 图片支持 / 缓存）+ **按学科指定**（物理用 pro，数学跟随默认） |

三条设计决定：

1. **价格写在列表里**，不藏在详情页。你是自己掏钱，选模型时价格必须第一眼看到。
2. **思考档位单独成组**，不进模型项——因为它是每次提问都可能变的（讲题要"中"，概念辨析要"高"）。
3. **"按学科指定"是可选项**，默认跟随全局。物理/数学用 pro、英语用 flash，这种组合很自然。
4. 底部注明 **目录来自 Pi**（`pi update --models`），我们只是选——呼应 06 的结论。

## 5. 设置页：每个条目配图标

v3 的设置是一列纯文字。v4 每一项前面有图标（名字/说话方式/上限/保留率/开场/打扰/外观/模型/数据），右侧是值。

> 规则：**图标只用来"指认条目"，不用来装饰**。所以尺寸统一 15px、颜色取 `ink3`，不搞彩色图标墙。

## 6. 字号纪律（这轮又检查了一遍）

v4 的 HTML 里**没有一个非 token 的 `font-size`**（脚本替换后验证为 0 个）。

| Token | 值 | 用途 |
|---|---|---|
| `s1` | 34 | 大数字、引导标题 |
| `s2` | 24 | 页面标题、学科名 |
| `s3` | 19 | 她开口的第一句 |
| `s4` | 15 | 正文 |
| `s5` | 13 | 次要说明 |
| `s6` | 11 | 标签、元信息、图标旁的注释 |

间距仍是 7 档（4/8/12/20/32/52），三级面（flush / outlined / filled）不变。
