# 19 · 导航补齐 · 三态 · 手机 compact

> 稿：`design/mockup/result-ui-v9-nav.html`（6 屏）· `-v9-states.html`（6 屏）
> 你说的那句「拍题页面没有退出按钮，很多都没有，不返回」，这轮是**把它抽成组件**，不是逐页补箭头。

---

## 1. 问题：退出控件是"各画各的"

之前 18 屏的退出有五种写法：

| 写法 | 出现在 |
|---|---|
| 孤立小箭头 `‹`（14px，ink3） | 采集校对、上传队列（**没有**） |
| `✕` 图标（无热区） | 复习、知识点详情 |
| 纯文字「‹ 设置」 | 数据导出、诊断、模型管理 |
| **什么都没有** | **拍题取景**、**题目详情**、**找旧题**、**四条弹层** |
| 只有下拉把手（grab） | 模型/摄像头/确认/附件 sheet |

具体欠账：

- **拍题页**：只有一个语义不明的 `‹`（而且是 14px 灰的，几乎看不见）—— **拍摄中应该是 `✕` 关闭**；
- **题目详情**：完全没有退出；
- **找旧题**：没有返回；
- **上传队列**：没有返回；
- **四条弹层**：只有一条把手，没有 `✕`（依赖点遮罩，但不明显）。

---

## 2. 规范：四类页面，四种退出

| 页面类型 | 控件 | 位置 | 规格 |
|---|---|---|---|
| **L0 一级**（rail 六项） | 无 | — | 靠 rail 切换 |
| **L1 二级**（卡片展开 / 设置子页） | `‹` 返回 | 左上 | 44×44dp 热区，图标 18px，`ink2` |
| **全屏流程**（拍题 / 复习 / 引导） | `✕` 关闭 | 左上 | 同上，但**语义是"取消这次"** |
| **弹层 sheet** | `✕` 关闭 | 右上 | 44×44dp，`ink3`；**同时保留点遮罩关闭** |
| **表单** | `✕`（上）＋「取消」（下） | — | 两条路都能出去 |

**四条硬规则**：

1. **任何返回/关闭都是 44×44dp 热区**（图标 14–18px，但热区不能小）；
2. **颜色用 `ink2` 而不是 `ink3`** —— 之前用 `ink3`（`#A09B90`）在浅色底上对比度勉强，看不清；
3. **每页必须有标题**，标题与返回同一行（`‹ 题目`、`✕ 拍题`）；
4. **副标题写"我在哪"**（`错题` / `数学 · 必修一` / `受力分析 · 3 / 15`），不写解释。

## 4. 三态（v9-B S1–S3）

18 屏里有一半在"没数据"时会开天窗。而**头一周恰恰全是空数据**——那才是你第一眼看到的样子。

| 态 | 组件 | 规则 |
|---|---|---|
| **空态** | `.empty` | 一个 34px 灰图标（描边 `--stroke-soft` 1.4px）+ 一句标题 + 一句说明（≤36 字）+ **一个动作** |
| **加载态** | `.skel` | **骨架条**（14px 高、圆角 7、微光扫过），**不用转圈**——转圈不知道要等多久，骨架能预估形状 |
| **错误态** | `.err` | 一个 clay 图标 + **说清是什么错**（"连不上服务器"）+ **给一条退路**（"本地还有 12 张卡可以复习"）+ 两个动作（离线复习 / 重试） |

三条设计决定：

1. **空态必须给动作**。只写"还没有错题"是把人晾在那儿；写「还没有错题 + 拍一页」才是邀请。
2. **错误态必须给退路**。"连不上"之后如果只能说"重试"，你就被卡死了；所以同时给「离线复习」。
3. **骨架而不是 spinner**。复习/错题都是列表，骨架能预告"接下来是两列卡片"。

## 5. 手机 compact（v9-B S4–S6）

规则一直没变（`docs/09`）：**<600dp 无 rail，卡片整页替换**。

| 屏 | 处理 |
|---|---|
| **S4 对话** | 顶栏压成一行（名字 + 学科 + ⋯）；输入框收窄，去掉麦克风（手机上语音不如平板上手） |
| **S5 卡片整页** | `‹ 今日 / 物理` + 右上「开始」；内容变成**分组清单**而不是双栏卡片；底部固定「开始复习」 |
| **S6 拍题** | 全屏 + `✕` + 摄像头 chip；快门更大（64px），相册入口在左 |

> 手机和手机拍摄现在**不是主路径**（平板前摄才是），所以只做"能用"，不做专属优化。
