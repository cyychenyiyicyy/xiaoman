# 35 · 资料库、双栏预览、知识卡片与闪卡

> 技能生成的东西开始变多了，需要一个地方收；产物也不该每次都跳新窗口，应该能在右边看。
> 这一版把「生成 → 收藏 → 预览 → 再打开」补成了闭环。

代码：`server/app/api/learn.py`（列表/预览接口）· `server/app/services/{artifacts,cards}.py` ·
`agent/skills.json`（5 个技能）· `agent/server.mjs`（工具）· `web/app.js`（资料库/预览/技能与工具显示）
· 迁移 `a1b2c3d4e5f6`

---

## 1. 资料库

侧栏新增 **资料**（`#library`）：

- 按时间分组，卡片显示类型、学科、大小、日期；
- 顶部筛选：**全部 / 网页 / PDF / 卡片 / 闪卡**；
- 点卡片 → 右侧预览，不再跳新标签页；
- 空态给「去对话」动作，错误态给重试。

数据来自 `GET /api/v1/artifacts?kind=&limit=`，返回 `items/total`；文件仍在 `data/artifacts/`，
`GET /artifacts/{id}` 直接打开，`?download=1` 下载。

## 2. 双栏预览

点产物卡（对话里或资料库里）→ 右边出现预览栏：

```
┌ rail ┬ 对话列表 ┬ 对话 / 产物卡 ┬ 预览栏 ┐
│      │          │              │ 标题   │
│      │          │              │ 网页   │
│      │          │              │ iframe │
└──────┴──────────┴──────────────┴────────┘
```

- HTML / PDF / 闪卡用 `<iframe>`，知识卡片（PNG）用 `<img>`；
- 顶部：标题、类型、大小、**新窗口**、**下载**、关闭；
- 宽度 `min(42vw, 680px)`；窗口 ≤1500px 时自动收起对话列表，给聊天留出宽度；
- 手机（≤900px）变全屏，关闭按钮回对话；
- `body.preview-open` 只是状态标记，组件不各自判断。

> 参考的是 Claude Artifacts 那类「对话旁边开一个产物面板」的做法：不打断对话，又能边看边问。

## 3. 新技能（参考开源项目）

| 技能 | 交付 | 参考 |
|---|---|---|
| **知识卡片** | 1080×1440 PNG，一张只讲一个点 | [make-knowledge-cards](https://github.com/xv-xiong/article-to-knowledge-cards)：一张卡一个知识点，四字段（标题/核心/解释/例子或自测），不编造 |
| **记忆闪卡** | 自包含 HTML，点一下翻面 | [the-learning-skill](https://github.com/toddward/the-learning-skill)：学习会话留下 notes / flashcards / quiz；[cram](https://github.com/sjquant/cram)：闪卡做成离线可用的单文件 HTML |

**知识卡片**的模板刻意做得像一张可以存进相册的卡片：

- 顶部 brand + 学科，大标题，赤陶短线；
- 正文四段：一句话结论 → 核心知识 → 一个例子/自测 → 易错点；
- 公式走 KaTeX；页脚「一张卡片只讲一件事」；
- 服务端把 Markdown 排成 1080×1440 的页面，用 Edge 截图成 PNG（不引图片生成模型，结果稳定、可复现）。

**记忆闪卡**是自包含 HTML：

- `cards: [{front, back}]` 3–8 张；
- CSS 3D 翻面，点卡片切换；键盘可聚焦；
- 正反面字段分离，公式同样走 KaTeX；
- 下载后仍可打开（KaTeX 是站内路径，离线时公式退化为文本）。

两个技能都走 `agent/skills.json`，加技能只改这个文件。

## 4. 技能与工具怎么显示

### 4.1 对话里

- 用户消息保留技能小 tag（`知识卡片`），知道这句话用的什么；
- assistant 消息顶部一行：**`技能 · 知识卡片`**；
- 思考条折叠时就直接写工具名：**`思考 8 秒 · 生成知识卡片`**；
- 展开后每个工具一行：`生成知识卡片` / `查题库` / `生成 PDF` ……

工具中文名统一在 `TOOL_META`：

```js
make_webpage: ['生成讲解网页', 'globe']
make_pdf: ['生成 PDF', 'book-open-text']
make_card: ['生成知识卡片', 'image']
make_flashcards: ['生成记忆闪卡', 'book']
quiz_create: ['出题检测', 'circle-dot']
```

### 4.2 技能弹层

每个技能除了名称/说明，还显示 **`工具：生成讲解网页`**，选之前就知道它会调什么。

### 4.3 数据

assistant 消息也写 `skill`（这一轮用的技能），所以刷新后还能显示；`Message.skill` 原来只给 user 用，
现在两条都写。

## 5. 接口与数据

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/artifacts?kind=&limit=&offset=` | 资料库列表 |
| GET | `/artifacts/{id}` | 打开（HTML/PDF/PNG/闪卡） |
| GET | `/artifacts/{id}?download=1` | 下载 |
| POST | `/internal/tools/make_card` | 生成知识卡片 PNG |
| POST | `/internal/tools/make_flashcards` | 生成记忆闪卡 HTML |

`artifact.kind`：`html`（讲解网页）· `pdf` · `png`（知识卡片）· `flashcards`（记忆闪卡）。
迁移 `a1b2c3d4e5f6` 把 `kind` 从 8 放宽到 16。

## 7. 已知限制 / 下一步

| 项 | 说明 |
|---|---|
| 资料库不能删/改名 | 目前只读；下一步加长按菜单（删除、重命名、下载） |
| 没有版本 | 重新生成会多一份；还没有「基于这份再改」 |
| 卡片内容溢出 | 1080×1440 固定尺寸，模型写太长会被裁；提示词已限制 350 字 |
| PDF 预览依赖浏览器 | iframe 里是浏览器 PDF 查看器；有的环境不内置就显示空白，可点「新窗口」 |
| 闪卡没有复习记录 | 只是自测工具，还没和 `kp_evidence` / FSRS 打通 |
| 搜索/标签 | 资料库只有类型筛选，还没有按知识点/关键词搜 |
