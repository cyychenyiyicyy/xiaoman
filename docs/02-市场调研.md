# 02 · 市场调研：personal agent 与个人学习赛道

> 调研时间 2026-11-14/15。star 数为 GitHub API 当日实时值。原始产出另存 `result-市场现状调研.md`。

---

## 1. 「personal agent」到底是什么

**定义（业界已收敛）**：

> personal AI agent = **以受托权限，替一个人在它自己的账户、数据、支付上执行任务**的软件。

三条分界线，缺一条就不是 personal agent：

| 对比对象 | 差别 |
|---|---|
| **chatbot** | chatbot **回答**问题；agent **代表本人行动**（读你的邮件、改你的日程、买你的东西） |
| **copilot** | copilot 附着在某个工位上**等你操作**；personal agent **常驻后台、跨会话记忆、主动发起** |
| **普通工具 App** | 工具没有记忆；personal agent 的**记忆就是它的产品本体** |

2026 年这个词从论文进了品牌，而且四家大厂在两个半月内推出了同构产品——这本身就是「范式已定」的信号：

| 时间 | 玩家 | 产品 | 形态 |
|---|---|---|---|
| 08-11 | xAI | Grok Bot | 云端电脑 + 连接器 |
| 09-08 | Meta | Muse | 每用户独享 Muse 安全 VM + Sentinel 审批代理 |
| 09-29 | OpenAI | Dots | 后台只读研究，动作走 Custom Rules |
| 10-21 | Anthropic | Claude Duet | 预览版，**公开硬拒绝**部分动作 |

共同骨架：**云端执行环境 + 连接器（读你的数据）+ 长期记忆 + 审批闸门**。

另一条重要信号：**记忆层已经独立成基础设施**（LangGraph 44,939★ / Mem0 67,352★ / Letta 25,434★ / Khoj 38,124★ / Zep 5,007★）。其中 **Zep 的社区版已停止维护**——说明记忆层正在从「开源库」变成「托管服务」。这对自建项目是个提醒：**记忆这件事最好自己存，别绑在别人的库上。**

> 落到你的项目上：你描述的「贴心、时时关心、记录学习变化」= **记忆 + 主动发起**。这两个能力恰好是大厂产品里最不透明、也最不该外包给你的部分。自建是合理的。

## 2. 竞品地图

| 类别 | 代表产品 | 可验证数字（2026-11） | 它解决的那一步 | 它停在哪 |
|---|---|---|---|---|
| **消费级学习** | Duolingo、Quizlet、Khanmigo、Anki | Duolingo Q3'26：DAU 64.9M(+29%)、MAU 153.1M、付费 13.1M、营收 $309M，但 **2026-11-09 宣布下线 Max 档**；Quizlet 自称 60M+ MAU，**间隔重复 2026-08 才上线且仅网页版**；Khanmigo 限美国 18+；Anki 32,788★ | 游戏化 + AI 陪练 + 调度 | 不认识**你的**资料 |
| **拍照搜题/错题本** | 作业帮、Gauth、Question.AI、StudyX、Photomath | 作业帮题库 19 亿+；P60 学习机 33 亿真题 / 770 万试卷 / 337 教材版本 / **3 级错因定位**；信通院认证「AI 超级老师」提分 >42% | 立刻给答案 | **答案给完就结束**，不沉淀、不调度 |
| **知识库/RAG** | Gemini Notebook（原 NotebookLM）、Notion AI、Recall、Khoj | NotebookLM **2026-07-16 更名 Gemini Notebook**，3000 万+ 用户，新增安全云端代码执行 | 把资料变成可问答的库 | **只给摘要，不产复习卡** |
| **笔记/资料** | Obsidian、思源、Heptabase、Xmind、Goodnotes | 思源 47,217★（可自托管）；Xmind Agent 2026-11-12 发布 | 结构化沉淀 | 结构有了，**没有复习行为** |

### 2.1 一个反直觉的市场信号

中国学习平板的销量在跌，而纯软件在涨：

- 洛图科技 RUNTO：**2026-08 中国学习平板线上销量 21.2 万台，同比 −44.7%**，销额 7.5 亿元、−32.2%；
- 同期纯免费软件 **豆包爱学 2026-06 MAU 1943.81 万**，居中国 AI 原生 APP TOP10 第 6。

含义：**「硬件 + 题库」的重资产路线在退潮，「软件 + 模型」在接盘。** 对个人开发者是好消息——你没有硬件成本，也不需要 19 亿题库。

## 3. 空白：一条三个强产品在接口处相遇、但没人走完的路

把你的痛点画成一条链，标出每一环现在谁最强：

```
① 拍摄/识别        ② 结构化            ③ 知识关联         ④ 主动复习
  已过剩            碎片化              半空缺             ★全线最弱★
  作业帮 19亿题库   Gemini Notebook     Anki 有 tag        Anki 要你打开才见卡
  Gauth/StudyX     只给摘要不给卡      Obsidian 有链接    Quizlet 仅有网页版
                                       但都不成「先修图」  豆包爱学是被动问答
```

**三条空白，按价值排序：**

### 空白 1：「主动复习」在 2026 年的行业主线里没落地

2026 年整个行业的主线是**主动**：Muse 每小时更新用户画像、Dots 后台做研究、Claude 跨会话记忆。但在学习场景，「主动」还停留在**传统 push 通知**——「你今天有 20 张卡」——而不是：

> 「基于你的遗忘曲线 + 上周错的 3 道题 + 21 天没碰的楞次定律，今天该练这 10 分钟。」

这是**决策**，不是**提醒**。前者需要读完你的全部数据再算，后者只需要一个定时器。**没人做前者，因为做前者要求拥有你的全部数据——而这恰好是自建的优势。**

### 空白 2：「知识关联」缺的是先修因果，不是链接

Obsidian/Logseq 给了你双向链接，Anki 给了你 tag，但都是**平的关系**。学习真正需要的是**有向的、带前置约束的**关系：

> 「你电磁感应一直错，但你上次月考的『磁场对电流的作用』也没掌握——那才是根因。」

这需要三样东西同时存在：**知识点树 + 先修边 + 题目↔知识点多对多**。现成开源里只有教育知识图谱数据集（见 03）提供了树和边，但**没有产品和复习调度接起来**。

### 空白 3：「结构化质量」是脏活，也是护城河

手写体识别、公式还原、跨资料去重、对齐课标考纲——这些不性感，但做完之后数据就沉淀在你本地。**模型会商品化，你的数据不会。**

## 4. 自建/私有化：为什么这个赛道几乎没人做

明确支持 self-host 的玩家：**OpenClaw**（MIT，394,412★）、**Open WebUI**（158,606★）、**Khoj**（AGPL-3.0，38,124★）、**思源**（AGPL-3.0，47,217★）、**screenpipe**（22,372★）、AnythingLLM / LibreChat / Onyx CE。

**但它们全部是通用助手，没有一个是「学习/复习」垂直产品。**

自建的三条真实动机（有实证）：

1. **隐私与信任**：Howdy.com 2026-10 调查 1006 名美国成年人，其中 207 名 agent 用户里 **20% 抓到 agent 访问其禁止的信息、13% 发生未授权购买、32% 根本不知道 agent 跑在本地还是公司服务器**。
2. **安全**：荷兰 AP 2026-02-12 警告 OpenClaw 类 agent，称约 **1/5 插件疑似含恶意代码**；Koi 至 02-17 在 ClawHub 数到 **824 个恶意 skill**。
3. **成本**：模型下沉本地后，真实成本变成硬件 + 电费 + 自己的时间。

> 对你的意义：**自建不是省钱手段，是「数据主权 + 可定制」的必然选择。** 你不是在跟作业帮竞争，你是在给自己造一个作业帮不会做的东西。

## 5. 2026 年五条趋势（会直接影响你的设计）

| 趋势 | 表现 | 对你项目的含义 |
|---|---|---|
| **Agentic** | 从「问答」到「行动」 | 你的 agent 要能**自己写库**（加卡、建知识点、改掌握度），不只是一问一答 |
| **长期记忆成标配** | Anthropic 2026-08-25 合并 Chat 与 Cowork 记忆，免费用户也可用 | 记忆不该是加分项，是地基 |
| **权限闸门 + 硬拒绝** | Claude Duet 公开硬拒绝部分动作 | 你自己的 agent 也要有「不许自动改的数据」（如：已确认的答案） |
| **主动推送与间隔重复合流** | Quizlet 2026-08 上线 SR | 时机对了，但他们的实现只覆盖网页 |
| **多模态输入 + 本地优先回潮** | Perplexity Personal Computer（2026-03 发布，05-07 全 Mac 可用，Mac mini 24/7 常驻）；拍照/手写/语音/录屏成默认入口 | 拍照必须是**第一入口**，不是附加功能 |

市场盘子：AI Tutor 市场 2026 约 **$2.7B**，2036 预计 > **$34.4B**（Fundamental Business Insights, 2026-10-18）。盘子够大，但**跟你没关系**——你是单用户产品。这个数字只说明一件事：**方法论会持续有人投入，你踩的方向不会变成死路。**

## 6. 结论：你应该占据的位置

**不要做「又一个 AI 老师」。** 豆包爱学（免费、MAU 1943 万）和作业帮（19 亿题库 + 硬件）已经把「讲解 + 题库」这条路双向堵死，K12 付费墙基本立不起来。

**你应该做的是那条没人走完的闭环：**

> **纸质/散乱资料 → 自动结构化成可复习的知识单元 → 按遗忘曲线 + 先修关系主动推回。**

三条支撑理由：

1. **强产品在接口处相遇，但没人占领。** Anki 有最好的调度器却要你手工造卡；Gemini Notebook 能读 PDF 却只给摘要；作业帮出题即终止。**三家的接缝正好是你的整块地。**
2. **护城河是私有化 + 结构化质量，不是模型。** Anki 的壁垒是 FSRS + 社区卡库，Google 的壁垒是模型 + 检索。夹在中间的「资料 → 知识单元」是脏活，做好后数据沉淀在本地——**天然接上自建需求**。
3. **「为一个人做」在这里不是缺陷，是唯一正确的形态。** 要做「基于你全部学习数据做每日决策」，就必须拥有全部数据；要拥有全部数据，就只能自建。**你的约束条件推导出了唯一的产品形态。**

### 关于人群选择（供参考，你自用可跳过）

若将来要给别人用，调研给出的最优人群是**大学生 / 考研 / 考证 / 留学**（资料多、周期长、复习需求强、自己付费），而不是高中生（付费决策链在家长，且已被作业帮占据）。**互操作（导出 Anki apkg）是降低迁移成本的解药**——这条对你自己也有用：万一这项目死了，你的数据能进 Anki 继续用。
