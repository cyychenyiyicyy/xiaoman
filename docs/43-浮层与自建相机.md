# 43 · M3 浮层与自建相机（alpha 0.3）

## 1. 浮层规范：不再全部用右侧长 sheet

按 Material 3 的三类 modal 重新分工：

| 类型 | 用途 | 规格 |
|---|---|---|
| **Bottom sheet** | 选择、轻量操作：加号、技能、学科、主题、界面大小、资料菜单 | 平板居中 `max 640`，底部 `24` 间距；手机贴底全宽；28dp 圆角 + 32×4 拖动条 |
| **Side sheet** | 大内容：模型选择/管理、题库选择、来源、题目引用 | 宽 `360`，贴右满高，左侧 24dp 圆角 |
| **Dialog** | 确认/危险操作：删除记忆、断开 provider | 宽 `max 360`，居中，28dp，标题 24，文字按钮右对齐 |

其他统一项：

- scrim 32%；
- sheet 标题 20/24，正文 24 边距；
- 列表行 56dp，去掉“卡片套卡片”的边框；
- 动画 180–220ms，标准 ease-out；
- 关闭按钮 44dp，点 scrim 也可关。

实现：`web/app.js` 的 `renderOverlay()` 给 `.sheet` 加 `sheet--bottom / side / dialog`；`web/theme-md3.css` 定义三种布局。

## 2. 自建相机

- **CameraX 1.4.2**（core / camera2 / lifecycle / view），不引 Compose / AppCompat / Material Components；
- 默认 **后摄**；无后摄退前摄；两者都有才显示切换；
- 闪光灯只在后摄且硬件支持时出现；
- 3:4 / 4:3 圆角取景框；
- 拍完进入**自建确认页**：重拍 / 使用，不直接返回；
- 相册入口选图后先复制到 App cache，再进确认页，避免依赖别的 App 临时授权；
- 关闭 / 返回 = 取消；权限拒绝有同风格面板 + 去设置 / 相册；
- 方向：CameraX targetRotation + EXIF 像素级转正，长边 >3840 先降采样；
- 结果以 `content://` 返回 WebView，继续走原有上传/自动矫正/复核流水线；
- 抛掉系统 `ACTION_IMAGE_CAPTURE`。

代码：

- `android/.../CameraActivity.java`
- `CameraFiles.java`（EXIF/方向/相册）
- `CaptureFrameView.java`（取景框）
- `MainActivity.onShowFileChooser`：capture 走 `CameraActivity`，其他仍系统文件选择。

## 3. 签名与升级（重要）

0.2 是 GitHub Actions runner 临时 debug key 签的，和 0.3 的固定 key 不同：

- **从 0.2 升级到 0.3 需要先卸载一次**（会清掉本机 WebView 的服务器地址/登录 Cookie，不会动服务器数据）；
- 卸载后重新填服务器地址 + 访问密码；
- 0.3 起使用仓库内固定 debug keystore（`android/keystore/xiaoman-debug.jks`），后续 alpha 可以覆盖安装。

> 这个 keystore 只用于自用 alpha debug 签名，不是 Play 发布密钥。公开仓库意味着任何人可以拿它签同名包；只从官方 Release 下载 APK。
