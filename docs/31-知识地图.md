# 31 · 知识地图（P5）

> 目标：把 `kp` / `kp_edge` / `question_kp` 变成一张**能看、能点、能顺着先修链走**的图。
> 入口是侧栏「地图」，**一科一张图**：学科 → 教材模块 → 章 → 知识点。

对应代码：`server/app/api/kp.py`（`GET /kp/graph`）· `web/app.js`（`map*` 一组函数）·
`web/theme.css`（`.map*`）· `web/vendor/cytoscape/` · `web/index.html`（rail 地图）

---

## 1. 为什么是 Cytoscape.js

调研过 [Cytoscape.js / AntV G6 / ECharts / vis-network 的对比](https://juejin.cn/post/7480910706516115519)，
也翻了两个同类的 K12 开源实现：

| 项目 | 图库 | 值得抄的地方 |
|---|---|---|
| [xiaoyang111222/cn-math-taxonomy](https://github.com/xiaoyang111222/cn-math-taxonomy) | **Cytoscape.js + dagre**（vendor 内置，不走 CDN） | 局部先修图：选中一个点，只画它向上 N 层的祖先和向下 1 层；盒子节点 + 从属边 |
| [活书 learning-agent](https://pypi.org/project/learning-agent/) | vis-network | 掌握度热力边框、点节点下钻 |
| 通用对比 | G6 / ECharts / D3 | G6、ECharts 都能画关系图，但体积和构建成本更高 |

**选 Cytoscape.js 的理由**：

- MIT；单文件 min 版 **373KB**，直接 vendor 进 `web/vendor/cytoscape/`，和 KaTeX 一样**零构建、不连 CDN**；
- 自带 `cose`（力导向）、`concentric`、`breadthfirst`、`preset` 布局，pan / zoom / drag / 事件全有；
- 节点样式是 CSS 风格的，颜色可以直接读我们的 token（`--clay` / `--ink3` …）；
- 已知代价：没有 dagre 就不做严格分层（我们没引 dagre，`.js` 只有 373KB）。

> 结论：**不手写 canvas 力导向**，用成熟库；但布局参数、标签策略、聚合边是我们自己的。

## 2. 数据：一个接口给全科

`GET /kp/graph?subject=化学` 一次返回一科的全部节点与边（前端按模块 / 章切，不再请求）：

```json
{
  "subject": "化学",
  "modules": [{ "name": "必修 第一册", "points": 127, "chapters": 5 }],
  "nodes": [
    { "id": "ch_…", "kind": "chapter", "name": "第一章 物质及其变化", "module": "必修 第一册", "points": 30 },
    { "id": "uuid", "kind": "point", "name": "离子反应发生的条件", "parent": "ch_…",
      "module": "必修 第一册", "chapter": "第一章 物质及其变化", "grade": "高一",
      "q_count": 1, "difficulty": 0.55 }
  ],
  "edges": [{ "id": "…", "source": "uuid", "target": "uuid", "type": "prerequisite" }],
  "stats": { "points": 715, "chapters": 26, "edges": 491, "tagged": 8 }
}
```

- 节点：`kp` 的章节（`kind=chapter`）+ 知识点（`kind=point`），`q_count` 是题库里挂了几道题；
- 边：`kp_edge` 三种（`prerequisite` / `leads-to` / `related`），**只同学科**（迁移里的触发器保证）；
- 模块按教材顺序排（必修 → 选择性必修），章按中文序号排（第一章 → 第二章 …）；
- 模型补建、没有章节归属的点归到「其他」模块 / 「其他知识点」章，不丢。

## 3. 界面与交互

```
知识地图   化学 · 必修 第一册 · 第二章 海水中的重要元素
[语文][数学][英语][物理][化学][生物][政治][历史][地理]
[必修 第一册 127][必修 第二册 208][选择性必修1 …][其他 9]
[总览][第一章…][第二章…][第三章…][第四章…][绪言]       [搜知识点][搜索]
┌ 图（画布）──────────────────────────────┐ ┌ 侧栏 ────────────┐
│   ·─────▸·   点 = 知识点                 │ │ 第二章 …          │
│   │  ╲                                   │ │ 34 个知识点 · 0 有题│
│   ·   ▸  ·   箭头 = 先修                  │ │ [知识点 chips…]    │
│  [＋][－][适应]        图例               │ │                   │
└─────────────────────────────────────────┘ └───────────────────┘
```

| 操作 | 结果 |
|---|---|
| 学科 chip | 换一科（每科各自记模块 / 章） |
| 模块 chip | 换教材模块；默认章**有题的优先**，都没题才按知识点多少（不会落在「绪言」） |
| **总览** | 章级聚合图：章卡片 + 章与章之间的先修边（边宽 = 聚合条数） |
| 章 chip / 总览里点章 | 进入该章的知识点网 |
| 点知识点（图上或侧栏 chip） | 选中 + 侧栏详情：题数 / 关联数 / 难度 / 先修 / 后继 / 已收录题目 |
| 先修 / 后继 chip | 跳到对应知识点；跨章会自动切章并居中 |
| 拖 / 滚轮 / ＋－ / 适应 | 画布移动与缩放 |
| 搜索 | 全科按名称找点；命中会切到所在章并选中 |
| 题目详情里的知识点 chip | 直接打开地图并定位到那个点 |
| 侧栏「在题库里看」 | 带着该知识点筛题库 |

节点语义只有两层：**点 = 知识点**（有题 → 浅赤陶底 + 赤陶边；没题 → 纸底描边；选中 → 赤陶实心），
**方框 = 章节**。没有第三种颜色 —— 掌握度要等 M2 的 FSRS 数据，现在不假装有。

标签策略：章节标签常显；知识点标签用 `min-zoomed-font-size` 做**按缩放显隐**，
太长省略，悬停出 tooltip，完整名字在侧栏里。这是 30+ 节点同屏还能读的前提。

## 4. 布局

- **章节内**：Cytoscape `cose`（力导向）→ 再跑一遍自己的**松弛**（节点最小间距 112，章节节点 150），
  最后 `fit`。力导向会被标签宽度坑，松弛是必须的。
- **总览**：不算力导向，直接按椭圆均匀放章卡片，边是弦 —— 5–11 个章时最稳。
- 主题：颜色在 `mountMap()` 时从 `getComputedStyle(:root)` 读 token，深浅色都走同一套样式。

## 6. 已知限制 / 下一步

| 项 | 说明 |
|---|---|
| 章级聚合边少 | 数据集的关系多数在章内，总览只有 2–10 条弦，不是每个模块都热闹 |
| 标签截断 | 30+ 点同屏时省略 + 悬停；想读全名用侧栏或缩放 |
| 没有掌握度着色 | M2 有 `review_log` 后再按掌握度给节点上色（sage / clay） |
| 没有动效 | M1.6 先不动；力导向是静态布局 |
| 只高中 | 初中知识点树还没导 |
