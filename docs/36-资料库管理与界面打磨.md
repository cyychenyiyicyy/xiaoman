## 1. 资料库管理

| 能力 | 做法 |
|---|---|
| **搜索** | `GET /artifacts?q=`：标题、学科、正文（`source_md` 前 6000 字）、知识点名，命中即返回；前端搜索框 + 回车 |
| **重命名** | `PATCH /artifacts/{id}`；资料卡「更多」→ 重命名；标题校验非空 |
| **删除** | `DELETE /artifacts/{id}`：删文件、删源文件、删行；前端二次确认 |
| **入口** | 资料卡右上「更多」菜单：继续改 / 重命名 / 下载 / 删除 |

> 搜索在服务端内存里做（单用户，最多 300 份），没有上 PostgreSQL 全文索引 —— 不值得。

## 2. 继续改（迭代产物）

「继续改」和重新生成的区别：**她手里有原稿**。

```
预览栏「继续改」/ 资料卡菜单「继续改」
        │
        ▼
输入框变成：[✦ 讲解网页 ×] [基于：离子反应的条件 ×]
        │  她输入「加一个易错点」
        ▼
POST /chat { skill, artifact_id }
        │
        ├─ 后端读 Artifact.source_md → artifact_context
        ├─ 网关把上下文写进 system prompt
        └─ Agent 按原结构改，调用 make_* 重新交付
                │
                └─ 新 Artifact.parent_id = 原 id（有版本链，不覆盖原稿）
```

- `artifact.source_md` 保存原始 Markdown（闪卡保存 cards JSON）；
- `message.artifact_id` 记录这句话基于哪份资料；
- `artifact.skill` 记住它由哪个技能生成，继续改时自动选中同一个技能；
- 新产物写 `parent_id`，旧稿保留，资料库里是两份；
- 用户消息气泡里出现「基于资料」小胶囊。

## 3. 闪卡复习

闪卡不再只是「翻着玩」：

- 背面翻过来后有 **记住了 / 没记住**；
- 点击 → `POST /artifacts/{id}/card-review` → 写 `kp_evidence`（`flashcard_right` / `flashcard_wrong`）；
- 知识点来自 `make_flashcards` 的 `kps`，服务端解析成 `artifact.kp_ids`；
- 闪卡文件里用 `__AID__` 占位，生成后回填 artifact id，所以自包含 HTML 也知道自己是谁。

这样闪卡和出题检测共用同一套证据，后面接 FSRS 时不用再改。

## 4. 卡片自适应与 PDF 兜底

- **卡片**：1080×1440 固定尺寸；渲染后 JS 量 `article.scrollHeight`，超了就从 27px 逐级缩到 17px，避免长内容被裁。
- **PDF 预览**：预览栏从 `iframe` 换成 `<object type="application/pdf">`，浏览器不能内嵌时显示「新窗口打开」的兜底。

## 5. 界面打磨

参考的 Agent 开源项目：

- [assistant-ui · Claude Artifacts 示例](https://www.assistant-ui.com/examples/artifacts.md)：对话 + 右侧产物面板，支持「让 AI 继续改」；
- [LibreChat](https://www.librechat.ai/) / [Open WebUI](https://openwebui.com/)：工具调用收敛成一条可展开的状态行，不把每个工具做成大卡片；
- [CopilotKit Open Generative UI](https://www.gateway3.net/zh/news/detail/copilotkit-open-generative-uiclaude-artifacts-agent-20921687)：产物在隔离 iframe 里渲染。

具体改动：

| 位置 | 之前 | 现在 |
|---|---|---|
| 用户消息里的技能 | 独立小胶囊，像贴在气泡外面 | **气泡内部开头的小胶囊**，和正文同一行 |
| 输入框技能 | 26px 高、独立一行 | 24px、贴输入内容最前；「基于资料」同排 |
| 产物卡 | 36px 图标 + 两个大按钮 | 卡片缩略图（PNG）/ 类型图标，预览按钮柔底，hover 描边 |
| 资料卡 | 纯图标 + 文字 | 卡片缩略图、更多菜单、hover 提亮、圆角统一 14px |
| 输入框 | 直角细边 | 18px 圆角，聚焦时 3px clay 光晕 |
| 工具条 | 重边框 | 轻背景，展开才变纸色 |

## 6. 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/artifacts?q=&kind=&limit=` | 搜索 / 筛选 |
| PATCH | `/artifacts/{id}` | 重命名（标题 / 学科） |
| DELETE | `/artifacts/{id}` | 删除文件与记录 |
| POST | `/artifacts/{id}/card-review` | 闪卡自评 → `kp_evidence` |

`message` 新增 `artifact_id`；`artifact` 新增 `source_md / skill / parent_id`（迁移 `c3d4e5f6a7b8`）。
