# 40 · MD3 / MICL 平板界面重设计

> 2026-11-17 · 可视稿 **[design/mockup/md3/index.html](../design/mockup/md3/index.html)**（浏览器打开，按 1280×800 平板设计）
> 本文回答三件事：为什么这样排、每个尺寸从哪来、怎么落到 Compose / Web。

---

## 0. 一句话

**把「纸感 v9」整体换成 Material Design 3，组件按 MICL 10.0 实现，布局从手机优先改成 1280×800 平板横屏的三栏 / 两栏自适应。**

不是换皮：导航从 7 项竖排 rail 重做，对话固定宽度改成 720 阅读栏，卡片展开从"右栏 360"改成"支持面板"，设置改成"列表 + 详情"，复习与拍题改成全屏流程。品牌赤陶 `#B0563A` 保留，但不再手写色板，而是作为 **种子色** 交给 M3 算法生成整套角色。

## 1. 依据（先查，再画）

| 依据 | 用到的结论 | 来源 |
|---|---|---|
| M3 断点 | compact < 600 / medium 600–839 / expanded 840–1199 / large 1200–1599 / XL ≥ 1600；窗口变宽时一般从 1 栏变 2–3 栏 | [Breakpoints – M3](https://m3.material.io/foundations/layout/breakpoints/overview) |
| M3 导航 rail | collapsed 96 / narrow 80 / expanded 220–360；中、大窗口用 rail，展开态适合空间充裕的大窗口 | [Navigation rail – M3](https://m3.material.io/components/navigation-rail/guidelines) |
| Android 大屏导航 | 平板横屏用 **rail 而不是底部导航**：手扶左右两侧时，侧边导航更好够到 | [Build adaptive navigation](https://developer.android.com/develop/ui/compose/layouts/adaptive/build-adaptive-navigation) |
| Android 大屏质量 | 自适应布局、多窗口、横竖屏、键盘/鼠标/触控笔；大屏上底部条/按钮/输入框不拉满宽；侧边栏替代底部栏 | [Large screens · Tier 2](https://developer.android.com/guide/topics/large-screens/tier-2-overview) |
| M3 自适应 | 结构、组件、整页布局都随窗口变化；不只是缩放 | [Layout overview](https://m3.material.io/foundations/layout/layout-overview/adaptive-design) |
| MICL 10 | M3 Expressive 的 Web 实现：原生 HTML + CSS，31 个组件，主题按 `--md-sys-color-*` / `--md-comp-*` | [MICL · GitHub](https://github.com/henkpb/micl) · [npm](https://www.npmjs.com/package/material-inspired-component-library) |

**MICL 覆盖到的（直接用）：** navigation rail、app bar、card、list、chip（assist/filter/input）、button（text/elevated/filled/tonal/outlined，xs–xl）、icon button、text field（filled/outlined）、dialog（basic/fullscreen）、side sheet、badge、divider、progress（linear/circular，含波浪）、switch、radio、snackbar、menu、button group。
**MICL 没有、按 M3 规格补的：** FAB（56 高 / 16 圆角 / primary-container）、消息气泡、对话流、统计条、知识图谱画布。

> MICL 的定位就是「把 M3 Expressive 带到普通 Web」，所以本版不是"用 M3 风格重画"，而是**直接跑 MICL 的组件 CSS**。`micl.css` 359 KB，压缩后更小，零运行时依赖。

## 2. 和 AGENTS §3 的关系（哪些被本版推翻）

用户这次明确要求 MD3 + MICL，**本版在视觉层覆盖 AGENTS §3.1 的旧约束**，但保留品牌与交互底线：

| 旧约束 | 本版 | 为什么 |
|---|---|---|
| 只用 Instrument Sans，禁止衬线 | **保留 Instrument Sans 作拉丁/数字**，中文回落系统黑体 | 不引入衬线；MICL 的 `--md-ref-typeface-*` 可换 |
| 字号只 6 级 34/24/19/15/13/11 | **改用 M3 类型阶梯**（36/32/28/24/22/16/14/12/11）+ 过渡档 | M3 规范；中文/数字需要少量过渡，下一轮收敛 |
| 间距只 7 档 4/8/12/20/32/52 | **4dp 基准**：4/8/12/16/24/32/48 | M3 的 4dp 节奏；旧 20/52 不再作为主档 |
| 三级面 flush/outlined/filled | **M3 表面角色**：surface / surface-container-* / outlined / filled / tonal | M3 的"面"是颜色角色，不是三种边框 |
| 赤陶 `#B0563A` 是唯一主色 | **赤陶仍是种子色**，但实际按钮色是算法生成的 `#8F4C37`（light）/ `#FFB59F`（dark） | M3 要保证 on-primary 对比度 ≥ 4.5；直接用 `#B0563A` + 白字只有 3.7:1 |
| Lucide，1.7 描边，14/18/22 | **Material Symbols Outlined**，24/20/18 | MICL 与 M3 的原生图标族；描边统一由字重控制 |
| 一屏最多一个 filled | **保留**：filled 只给主 CTA（复习/发送/解析） | 这条与 M3 不冲突 |
| 深色只换 token | **保留**：只切 `.light` / `.dark` | 与 M3 完全一致 |
| 没有会话列表 / 没有新建对话 | **不再适用**：产品已按 docs 26/27 加了对话侧栏与新对话 | 本版只重排，不改产品定义 |

**没有变的：** 单用户、无账号、无计费、无分享；学科 = 空间；写操作走确认；复习用 FSRS；不做游戏化；拍题用平板前摄 + 镜面。

## 3. 断点与布局

### 3.1 基准

设计画布 **1280×800 dp**（16:10，和 1920×1200 / 2000×1200 学习机同比例）。实际设备横屏约 **890–1280 dp**，落在 expanded / large；所以**双栏是默认形态**，单栏只是兜底。

| 宽度 | 导航 | 列表栏 | 内容 | 卡片展开 |
|---|---|---|---|---|
| **< 600** compact | 底部 navigation bar | 不显示（进 sheet） | 单栏满宽 | 整页 dialog |
| **600–839** medium | rail 80 | 不显示 | 单栏，内容 max 720 | 整页 / 全屏 dialog |
| **840–1199** expanded | rail 96 | 344 | 双栏 | 右侧 support pane 360 |
| **≥ 1200** large（本稿 1280） | rail 96 | 344 | 双栏，阅读栏 720 | 右侧 support pane 360 |
| ≥ 1600 XL | rail 96（可展开 220） | 360 | 三栏 / 更宽留白 | 可常驻 |

### 3.2 1280 的算术

```
rail 96
+ 列表 344
+ 间隙 24
+ 内容 776（阅读栏居中 720）
+ 右边距 24
= 1280
```

打开详情时**列表栏隐藏**，把 344 让给详情：

```
rail 96 + 内容 776 + 间隙 24 + 详情 360 + 右边距 24 = 1280
```

这是本版最重要的一个取舍：**不把"列表 + 对话 + 详情"三栏硬塞进 1280**。1280 放三栏，每栏都会低于 320，对话会掉到 40 字宽以下；所以详情态收起列表，回到"对话 + 参考"两栏——和 docs/09 的"功能是对话旁边的一栏"一致。

### 3.3 为什么是 rail，不是 drawer

Android 官方对平板的建议是：**横屏双手持握时，侧边 rail 比底部导航更好够到**。7 个一级目的地竖排在左侧，右手主要操作内容区，左手拇指落在 rail 下半段；不需要为了"看见导航"把抽屉拉出来。

- rail 96：图标 24 + 标签 12，选中态 `secondary-container` 胶囊 56×32；
- 设置钉在底部（`xm-rail-spacer` 撑开），和上面 6 个目的地分开；
- 不用 expanded rail：7 个中文标签展开后 220 宽，会把内容压到 1060，得不偿失。XL 屏再考虑。

## 4. 导航模型

| 层级 | 控件 | 退出 |
|---|---|---|
| L0 一级（rail 七项） | 对话 / 题库 / 资料 / 地图 / 记忆 / 本周 / 设置 | 无退出，靠 rail 切 |
| L1 列表 + 内容 | 对话列表 + 对话；题库；资料；设置 | 内容栏左上 `‹`（窄屏）/ 详情 `✕`（右栏） |
| 全屏流程 | 复习、拍题 | 左上 `✕` |
| 弹层 | 学科、技能、模型、题目详情 | 右上 `✕` + 点遮罩 |
| 表单 | 确认卡、编辑 | 顶部 `✕` + 底部取消 |

- **学科空间不是 rail 的第二列**：它是这个"空间"的上下文，放在顶栏标题右侧的胶囊里（`全部 / 数学 / 物理…`），点开是 10 项弹层。切学科 = 换空间，不新建对话。
- 每屏都有标题；标题与返回/关闭同一行。
- 空态给动作（新对话给 3 条建议 + 输入框）；错误态给退路（重试 + 返回）。
- 加载用骨架条（`.xm-skel`），不用转圈。

## 5. 颜色

### 5.1 生成方式

种子 `#B0563A` → `material-color-utilities` 的 **Tonal Spot**，contrast level 0。**关掉动态取色**（`dynamicColorScheme`），颜色是固定的 token 文件 [theme-clay.css](../design/mockup/md3/theme-clay.css)。

> M3 的 primary 不是种子本身：种子的 tone 47 会被拉到 tone 40（light）/ tone 80（dark），否则白字对比度不够。这是"品牌色"和"可读性"之间必须做的换算。

### 5.2 关键角色

| 角色 | light | dark |
|---|---|---|
| primary | `#8F4C37` | `#FFB59F` |
| on-primary | `#FFFFFF` | `#561F0E` |
| primary-container | `#FFDBD0` | `#723522` |
| on-primary-container | `#723522` | `#FFDBD0` |
| secondary-container | `#FFDBD0` | `#5D4037` |
| on-secondary-container | `#5D4037` | `#FFDBD0` |
| tertiary | `#6B5E2F` | `#D8C68D` |
| surface | `#FFF8F6` | `#1A110F` |
| on-surface | `#231917` | `#F1DFDA` |
| on-surface-variant | `#53433F` | `#D8C2BC` |
| surface-container | `#FCEAE5` | `#271D1B` |
| surface-container-high | `#F7E4DF` | `#322825` |
| outline | `#85736E` | `#A08C87` |
| outline-variant | `#D8C2BC` | `#53433F` |
| success（自定义） | `#4E6146` | `#A8C79A` |
| success-container | `#DDE8D3` | `#33472B` |

### 5.3 用法

| 位置 | 颜色 |
|---|---|
| 页面画布（rail 背后） | `surface-container` |
| 面板 / 卡片底 | `surface`（浮起 24 圆角 + 阴影） |
| 卡片内次级块 | `surface-container-low` |
| 选中项 / 导航激活 | `secondary-container` + `on-secondary-container` |
| 输入框 | `surface-container-high`；聚焦 1px primary |
| 用户气泡 | `primary-container` + `on-primary-container` |
| 主 CTA | `primary` + `on-primary`（filled）或 `primary-container`（tonal） |
| 已掌握 | 自定义 `success-container` / `on-success-container`（sage） |
| 待复习 | `tertiary-container`（暖黄） |
| 未掌握 | `primary-container`（陶土浅底） |

**颜色不是唯一信号**：状态点旁一定有文字（已掌握 / 复习中 / 未掌握），色盲用户也能读。

### 5.4 对比度（脚本实测）

| 组合 | light | dark |
|---|---|---|
| on-primary / primary | 6.45:1 | 7.74:1 |
| on-primary-container / primary-container | 7.25:1 | 7.25:1 |
| on-secondary-container / secondary-container | 7.23:1 | 7.23:1 |
| on-surface / surface | 16.36:1 | 14.42:1 |
| on-surface / surface-container-highest | 13.34:1 | 9.62:1 |
| on-surface-variant / surface | 8.92:1 | 10.93:1 |
| on-success-container / success-container | 11.86:1 | 7.16:1 |

全部 ≥ 4.5:1；正文实际在 8:1 以上。

## 6. 字体与字号

### 6.1 字体

```css
--md-ref-typeface-plain:
  "ISans", "Instrument Sans", "Noto Sans SC", "Source Han Sans SC",
  "PingFang SC", "Microsoft YaHei", system-ui, sans-serif;
```

- 拉丁与数字：**Instrument Sans**（项目原字体，保留）；
- 中文：系统黑体（平板是 Noto Sans CJK / MiSans）；
- 等宽：`ui-monospace`（公式/代码）；
- **不引入衬线**；公式里的斜体是 `<i>`/`font-style`，不是衬线字体。

### 6.2 类型阶梯

| token | 字号/行高 | 用途 |
|---|---|---|
| display-small | 36 / 44 | 新对话页大标题 |
| headline-large | 32 / 40 | 统计大数字、拍题后的强调 |
| headline-small | 24 / 32 | 页面 h2、弹层标题、报告标题 |
| title-large | 22 / 28 | 顶栏标题、sheet 标题、详情标题 |
| title-medium | 16 / 24 | 卡片标题、面板标题 |
| body-large | 16 / 26 | 对话正文、试卷正文 |
| body-medium | 14 / 20 | 次级正文、卡片说明 |
| label-large | 14 / 20 | 按钮、chip |
| label-medium | 12 / 16 | 元信息、标签 |
| label-small | 11 / 16 | kicker、日期分组 |

**过渡档（下一轮收敛）**：实际稿里还用了 13/15（中文次级）、18/19（数字与题干）、20/26/30（全屏标题、纸张标题、统计），这些是设计稿的临时值。下一轮统一收敛到 36/32/24/22/16/14/12/11 八档，见 §14。

### 6.3 数字

统计数字全部 `font-variant-numeric: tabular-nums`；"42 题 / 78% / 6 天"不会因为数字变化而跳动。

## 7. 形状、高度、动效

| 元素 | 圆角 | 高度 |
|---|---|---|
| 面板（pane） | 28 | 全高 - 48 |
| 卡片 / 消息卡 | 16 | 自适应 |
| 输入框 | 28 | 最小 48 + 工具行 |
| 弹层 dialog | 28 | fit-content（全屏除外） |
| 侧边 sheet | 28（朝内容的两角） | 全高 |
| 按钮 | full（M3 Expressive） | 40 / 56 |
| chip | 8 | 32 / 36 |
| FAB | 16 | 56 |
| 图标按钮 | full | 40 视觉 / 48 热区 |

- 表面高度用 **tonal elevation**（surface-container 阶梯），阴影只给浮起的 pane 和 FAB；
- 动效按 M3 Expressive：进入 400–500ms spatial spring，退出 200–300ms；rail 切换 150ms；面板展开 250ms；`prefers-reduced-motion` 全部降到 1ms；
- 触控反馈：MICL 的 ripple + state layer 已覆盖，按下 8% / 悬停 8% / 聚焦 12%。

## 9. 逐屏规格

> 所有尺寸是 1280×800 下的 dp/px。可视稿每个屏都能通过 hash 直接打开，见 [mockup README](../design/mockup/md3/README.md)。

### 9.1 对话 · 新对话（`#/chat`）

| 区块 | 规格 |
|---|---|

## 10. 平板操作习惯（不是"把手机放大"）

| 习惯 | 本版怎么做 |
|---|---|
| **横屏双手持握** | 导航在左边缘（拇指可及），主操作在内容区；不需要跨到屏幕顶部找返回 |
| **左手导航、右手内容** | rail 固定左侧；详情面板在右；关闭在右栏右上 |
| **底部拇指区** | 主 CTA 贴底：详情"在对话里继续问"、复习评分键、拍题快门/解析；输入框在底部 |
| **48dp 热区** | rail 项 56、列表行 56、图标按钮 48、FAB 56、评分 52、dialog 选项 56 |
| **手指遮挡** | 列表/内容都从顶部开始，底部只放固定操作；滚动内容不会被固定条盖住（composer / foot 有独立高度） |
| **误触** | 写操作走确认卡；不可逆操作不给 agent 工具；删除有确认 |
| **鼠标 / 触控笔** | 所有按钮有 hover 8% / pressed 8%；卡片 hover 抬阴影；草稿区支持手写（Web 端用 canvas，原生用 stylus） |
| **键盘** | Enter 发送 / Shift+Enter 换行 / Esc 关弹层 / 1–4 评分（原型已实现发送与 Esc；评分快捷键预留） |
| **多窗口 / 分屏** | 不锁横屏；600–839 单栏，≥840 双栏；窗口缩小自动收起列表 |
| **安全区** | `viewport-fit=cover` + `env(safe-area-inset-*)`；状态栏/手势条不压内容 |
| **护眼模式** | 底色 `#FFF8F6` 不是纯白；深色 `#1A110F` 不是纯黑 |
| **大字号** | 全部 rem/相对字号；列表行随字号变高（不写死高度） |

**三条硬规则**（沿用 docs/19）：

1. 每屏必须有标题，标题与返回同一行；
2. 左侧只放"出去"，右侧放"页内移动"（翻页器在右，不和关闭抢位）；
3. 空态给动作，错误态给退路。

## 11. 无障碍与深色

- 正文对比度全部 ≥ 4.5:1（见 §5.4），深色单独测算，不从浅色推断；
- 焦点环：2–3px primary，`focus-visible` 才出现；dialog 打开时焦点落在第一个可操作项；
- 图标按钮都有 `aria-label`；rail 用 `aria-current="page"`；抽屉/弹层用 `dialog` 原生焦点陷阱；
- 不用颜色单独表达状态：badge 带文字 + 点；
- `prefers-reduced-motion` 下所有 spring/波浪降为 1ms；
- 深色只切 `.light` / `.dark` 两个类，组件里没有 `if(dark)` 分支；
- 图片/试卷用固定浅色纸面，不随主题反色（真实纸张语义）。

### 12.2 MICL 接入的四个坑（本版已解）

| 坑 | 现象 | 解法 |
|---|---|---|
| **chip 不生效** | filter chip 露出原生 checkbox、input chip 裂成两块 | chip 必须放在带 `.micl-chips` 的容器里；`<fieldset class="micl-chips">` 或给容器加类 |
| **全屏 dialog 偏到左上** | `micl-dialog--fullscreen` 仍按 50%/translate(-50%,-50%) 定位 | 显式 `inset:0; inset-block-start:0; transform:none; translate:none` |
| **侧边 sheet 右边被切 40px** | MICL 给 40px `--_spring-buffer`，open 时 `margin-inline-end:-40px` | 覆盖 `--_spring-buffer:0px`，显式 `inline-size` + `inset-block:0` |
| **裁剪/窗口边距冲突** | `--md-sys-layout-window-margin` 同时影响 appbar 负 margin 和 sheet padding | 全局设 0，pane 自己给 24；sheet 单独补 `--md-comp-sidesheet-padding:24px` |

### 12.3 WebView 兼容性（重要）

MICL 10 面向 2026 的 Chromium：anchor positioning、`clip-path: shape()`、`@starting-style`、container style queries、`dvh`。**Chrome 157 完整渲染**；旧学习机的 WebView 如果是 Chrome 101（docs/09 记录过 Ekko Pad），会出现：

- dialog/sheet 的进场动画直接出现（可接受）；
- nav rail 的 badge 锚定失效（本版没用 badge，可接受）；
- 波浪进度退化成平条（可接受）；
- 极端情况下 `@container` 样式查询失效，wavy 100% 的方头（可接受）。

**建议**：上线前在目标平板打开 `chrome://version` 看 WebView 版本；< 125 时要么升级 WebView，要么保留旧界面，不要把 MICL 直接塞进旧壳。
