# 42 · 安全与数据边界

> 2026-11-19。回答两个问题：**公网开放危险吗**、**哪些是本地 / 哪些是云端**。

## 0. 结论先说

当前 alpha 的部署是：**公网 HTTP + Caddy UA 分流 + 单用户访问密码**。

- **有危险**，不适合长期直接裸奔在公网。
- **不是纯本地**：对话、图片、搜索会经过第三方云 API。
- UA 分流只是“不占端口/不影响原站点”的路由技巧，**不是鉴权**；数据鉴权在应用层。
- 访问密码已经加上：scrypt 哈希、HttpOnly 会话 Cookie、30 天、登录限速；但 **HTTP 明文传输仍未解决**。

## 1. 一次对话会经过哪些地方

| 数据 / 功能 | 位置 | 是否出公网 |
|---|---|---|
| 对话正文、历史、长期记忆 | 自己的服务器 PostgreSQL | 存储不出；但每轮会发给模型 provider |
| Pi 运行时 / 工具执行 / FSRS / 知识图谱 | 自己的服务器 | 否 |
| LLM 回答 | DeepSeek（或你配置的 provider） | **是**：当前对话上下文、图片（若模型支持） |
| 联网搜索 | DeepSeek Search（当前配置） | **是**：搜索词与结果整理 |
| 拍题 OCR / 自动矫正 / 切题 | 阿里云试卷切题 API | **是**：上传的题目图片 |
| 资料 / 试卷 / 上传图片 | 自己的服务器磁盘 | 存储不出 |
| Android 渲染、WebView 缓存、主题/缩放偏好 | 平板本地 | 否；无本地模型 |

所以：
- **“数据存在哪里”**：自己的服务器。
- **“处理在哪里”**：结构化业务（复习、图谱、检索、记忆）在自己的服务器；**AI 推理、联网搜索、OCR 在云端**。
- 如果换成本地模型（Ollama 等），LLM 这一段可以不出公网；OCR/搜索仍取决于 provider。

## 2. 当前公网风险

1. **HTTP 明文**：平板到服务器之间没有 TLS，路径上的网络设备可以读到对话、图片和登录 Cookie。
2. **静态壳公开**：未登录也能加载 UI，但所有 `/api` 数据接口需要会话。
3. **UA 可伪造**：Caddy 的 `User-Agent` 分流只适合路由，不是安全边界；真正的门是登录密码。
4. **成本风险**：虽然 API 已鉴权，但密码泄露后仍可调用模型/OCR/搜索。
5. **SSH 密码**曾在聊天里出现：应立即更换，并禁用密码登录、改用密钥。

## 2.1 登录实现

- 密码只存 `APP_PASSWORD_HASH`（scrypt，16k/8/1），仓库没有明文；
- 登录成功发 `xm_session`：HttpOnly、SameSite=Lax、30 天；会话在内存，服务重启失效；
- 除 `/auth/login`、`/auth/me`、`/auth/logout` 和 `/health` 外，所有 `/api` 都要会话；
- 内部网关请求用 `x-internal-token` 放行；
- 登录失败按 IP 限速（8 次 / 5 分钟）。

## 3. 建议的安全方案（按推荐顺序）

### A. Tailscale / WireGuard（最推荐）

- 平板和服务器加入同一个 tailnet；
- 小满只监听 Tailscale 私网地址，Caddy 不再把 UA 路由暴露到公网；
- 传输加密、设备级鉴权，不需要在 App 里加账号密码；
- 代价：平板要装 Tailscale，地址变成 `100.x.x.x`。

### B. 公网 + HTTPS

访问密码已加，但 HTTP 明文仍会让密码/会话在网络路径上可被截获。公网长期使用必须再加：

- 用域名 + Caddy 自动 HTTPS（IP 证书浏览器/WebView 不信任）；
- 或使用 Tailscale/WireGuard 的加密私网；
- 保留当前访问密码作为第二层。

### C. 临时缓解

- 换 SSH 密码，禁用 root 密码登录；
- 限制服务器安全组来源 IP；
- 不要把 `.env`、数据库、SSH key 提交到仓库；
- 定期看模型/OCR 账单。

## 4. 当前 alpha 的定位

这是**单人自用、内测**的部署，不是可以公开注册的产品。  
访问密码已经补上；但在完成 HTTPS/Tailscale 之前，建议只在可信网络使用，不要把地址和密码发给别人。
